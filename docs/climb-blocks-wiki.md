# 攀爬方块机制解析：梯子、藤蔓、脚手架、细雪与活板门（基岩版 1.26.51.01）

在《我的世界》基岩版（MCBE）中，攀爬方块的手感与跑酷判定与 Java 版存在多处显著差异：除了“梯子上开活板门爬不动”“光在边缘挨着梯子会掉下去”外，**基岩版藤蔓不限水平速度、脚手架直接摔上去也不扣血、穿皮革靴顶墙爬细雪比爬梯子快整整 50%**。

> **文档分工**：本文面向玩法理解、跑酷线路设计与 Java/Bedrock 差异对照，略去底层反编译地址与内部组件编号；完整逆向函数定位、单帧管线顺序与逐 tick 实测原始数据请参阅 [`notes/climb-blocks-12651.md`](notes/climb-blocks-12651.md)。
>
> **单位约定**：文中速度单位默认是 **格/tick**（$1\text{ 秒} = 20\text{ tick}$），括号内附 **格/秒** 方便直观对比。

## 一、一分钟结论速查

| 方块类型 | 触发条件 / 判定区域 | 上升（格/tick） | 被动 / 下降（格/tick） | 按潜行悬停 | 水平速度限制 | 摔落伤害 |
| --- | --- | --- | --- | --- | --- | --- |
| **梯子** 与 **4 种藤蔓**（普通/缠怨/垂泪/洞穴） | 仅看玩家**中心点**所在方块 | Space **`+0.20`**（`4.0` 格/s）<br>推墙 **`+0.20`**（`4.0` 格/s） | **`-0.20`**（`-4.0` 格/s）<br>*(Java 为 `-0.15`)* | 速度变负后归零 **`0.0`** | **无限制**（可满速疾跑穿过） | **`0`**（进入即清零） |
| **梯子上方的开活板门** | **不可攀爬** | 无 | 正常重力自由落体 | 无 | 正常空中 | 正常 |
| **脚手架** | 整个 **水平碰撞箱搭边** 即可 | Space **`+0.15`**（`3.0` 格/s）<br>*(悬空也能爬)* | 有支撑按潜行 **`-0.15`**（`-3.0` 格/s）<br>*(悬空不会穿底)* | 无（要么站顶面要么下穿） | 无攀爬专用限速 | **不按潜行也是 `0`** |
| **细雪 + 皮革靴** | 穿皮革靴（水平足迹 + 中心点双触发） | Space **`+0.225`**（`4.5` 格/s）<br>**推墙 `+0.300`**（**`6.0` 格/s**） | 按潜行 **`-0.225`**（`-4.5` 格/s）<br>*(穿入首拍 `-0.15`)* | 无 | 细雪水平减速 **`0.9×`** | **`0`** |
| **细雪（光脚）** | 任意方块内 | **无法上升**（按跳无效） | **匀速下沉 `-0.1176`**（`-2.352` 格/s） | 无 | 细雪水平减速 **`0.9×`** | **`0`** |

## 二、基岩版 vs Java 版核心差异

| 对比维度 | Java 版（JE） | 基岩版（BE `1.26.51.01`） | 实战 / 跑酷影响 |
| --- | --- | --- | --- |
| **梯子 / 藤蔓被动下滑** | `-0.15` 格/tick | **`-0.20` 格/tick** | 松手滑得更快，卡节奏跳要注意落差更大 |
| **梯子 / 藤蔓水平速度** | 钳制在 `±0.15` 格/tick | **完全不限速** | 地面疾跑（`0.2806` 格/tick）直接横穿藤蔓不会撞“隐形减速墙” |
| **梯子 / 藤蔓抓梯判定** | 玩家整个碰撞箱重叠即算 | 只看玩家**脚底中心点那一格** | 站在梯子边外侧、只靠身体蹭到梯子时按空格**爬不起来**，必须把中心线挤进方块内 |
| **梯子上方的开活板门** | 可以继续向上攀爬 | **完全不可攀爬** | Java 版常用的“半截梯子 + 一长串开活板门墙”在基岩版会直接摔下来 |
| **脚手架无潜行防摔** | 不按潜行直接摔在顶部会**正常扣血** | **不按潜行也是 0 伤害** | 基岩版高空救命放脚手架无需按住潜行（注意穿皮革靴掉进细雪会下沉 1 格但同样 0 伤） |
| **细雪 + 皮革靴攀爬** | `±0.15` 左右，无 `1.5×` 加成 | **全线放大 `1.5` 倍**：推墙高达 **`+0.300` 格/tick** | 靠着墙面在细雪里按 `W` 推进，爬升速度比梯子还快 50% |

## 三、梯子与藤蔓：单点判定、推墙 vs 空格、潜行刹停

全游戏只有**梯子**和**各色藤蔓**（普通藤蔓、缠怨藤、垂泪藤、洞穴藤蔓）拥有原生的“攀爬 + 潜行悬停”属性，它们在运动物理上完全一致：

1. **为什么身体碰到梯子却爬不起来？**
   - 基岩版判定是否在梯子/藤蔓上时，只检查玩家**中心点**（`(floor(x), floor(feet_y), floor(z))`）这一格是不是梯子。
   - 玩家碰撞箱宽 `0.6` 格（中心向两边各延 `0.3` 格）。实测将玩家放在梯子外侧 `0.15` 格位置（碰撞箱已经吃进梯子 `0.15` 格，但中心点落在空气里），按跳跃会直接自由落体；往里挪过边界后立刻恢复 `+0.20` 格/tick 攀爬。
2. **为什么不限水平速度？**
   - Java 版会在梯子/藤蔓内把 X/Z 速度压死在 `±0.15`；基岩版移动代码没有任何水平钳位，疾跑穿过藤蔓时水平速度照常跑到 **`0.2806` 格/tick**（`5.61` 格/秒）。
3. **空格上爬 vs `W` 顶墙上爬的小细节**：
   - 两者爬升速度都是稳定的 **`+0.20` 格/tick**，但**松键那一刻的手感不同**。
   - **按 Space 上爬**：松键第 1 帧就受重力和空气阻尼拖累，速度立刻变成 $(0.20 - 0.08) \times 0.98 = \mathbf{+0.1176}$ 格/tick，随后降为 `+0.0368`、` -0.0423`。
   - **靠墙按 `W` 自动攀爬**：游戏在检测到贴墙碰撞触发自动攀爬时，会在当帧附上“自动攀爬标记”，跳过该帧的重力 `-0.08` 与空气阻尼 `0.98`；松开方向键后的第 1 帧还会再多飞 1 拍完整的 `+0.20` 格/tick，下一拍才进入 `+0.1176` 减速。
4. **为什么往上跳时按潜行不会立刻定在半空？**
   - 潜行悬停只在**正在向下掉（垂直速度 `< 0`）**时才触发清零。如果你在攀爬上冲阶段松开空格同时按住潜行，角色会继续向上滑完惯性（`+0.1176 → +0.0368`），直到重力把速度拉到负值后才刹住并稳稳停在梯子上。
   - 悬停期间每拍结束时重力仍会预写入 `-0.0784`，下一拍再被潜行清零，所以**一旦松开潜行就会以 `-0.0784` 为初速起步下滑**，几拍后稳定在 **`-0.20` 格/tick**。

## 四、脚手架：搭边就爬、悬空不穿底、落地全免伤

脚手架走的是独立于梯子的检测系统，手感更加宽容：

1. **碰撞箱只要“搭到边”就能爬**：
   - 和梯子死盯中心点不同，脚手架每帧扫描玩家**整个脚底水平覆盖盒**内的所有方块。哪怕人站在旁边空气里、只有碰撞箱边缘擦进脚手架 `0.1` 格，照样可以按 Space 以 **`+0.15` 格/tick**（`3.0` 格/秒）往上爬。
2. **有支撑 vs 悬空脚手架的行为差异**：
   - **脚手架下面有支撑柱**：站在顶面上时，按住潜行会触发“下穿状态”，直接穿透顶面以恒定 **`-0.15` 格/tick** 匀速下降；松开潜行时因为下降状态仍然会跳过重力 `-0.08`，第 1 拍仅受空气阻尼影响变为 `-0.15 × 0.98 = -0.147` 格/tick，之后才逐步加速下落。
   - **悬空搭出来的脚手架（正下方是空气）**：站在上面时，下穿标志**不会激活**——按住潜行也只会被顶面实心托住，不会失足跌落；但如果人已经钻进悬空脚手架格子里，按 Space 依然能以 **`+0.15` 格/tick** 向上爬出顶面。
3. **为什么不按潜行摔上去也不扣血？**
   - 在 Java 版里不按潜行踩上脚手架无法免伤；但基岩版每帧更新脚手架状态时，只要检测到玩家处于脚手架内或站在脚手架顶部，就会顺手把累计摔落高度清零。因此基岩版直接跳进脚手架顶部、不管按不按潜行都**不会受到摔落伤害**。

## 五、细雪 + 皮革靴：为什么推墙能爬出 `0.30` 格/tick？

细雪是基岩版里机制最特别的一个组合——它同时吃到了**脚手架系统的上下门禁**、**梯子系统的自动攀爬**以及**细雪本身的 `1.5×` 垂直缩放**，三者叠加产生了全游戏最快的攀爬方式：

1. **三段倍率如何叠加成 `+0.300`**：
   - 穿皮革靴进入细雪后，系统既会触发类似脚手架的上升/下穿判定（Space 写入 `+0.15`，潜行写入 `-0.15`），又会满足梯子的 `isOnLadder` 判定（靠墙推动触发自动攀爬写入 `+0.20`）。
   - 紧接着移动结算阶段，细雪施加的**垂直方向 `1.5×` 乘数**会直接作用在这份移动位移上：
     - **雪中按 Space 原地上爬**：$+0.15 \times 1.5 = \mathbf{+0.225}$ 格/tick（`4.5` 格/秒）—— 已经比梯子快；
     - **雪中按潜行下穿**：从顶面开始下潜的首拍为 `-0.15` 格/tick，进入雪块内后稳态为 $-0.15 \times 1.5 = \mathbf{-0.225}$ 格/tick；
     - **雪中按 `W` 顶着旁边实心墙自动攀爬**：先由自动攀爬写入 `+0.20`，再乘细雪的 `1.5×` 缩放，实际速度达到 $+0.20 \times 1.5 = \mathbf{+0.300}$ 格/tick（`6.0` 格/秒），**足足比常规梯子快 50%**！
   - 唯一例外是优先级：在雪内同时按 Space 和推墙时，Space 会先一步在跳跃阶段走脚手架分支（`+0.15`）而非梯子分支（`+0.20`），所以跑细雪垂直柱想拿满 `6.0` 格/秒应该**只推墙、不按 Space**。
2. **光脚掉进细雪为什么不会越掉越快？**
   - 细雪的减速系统每 tick 处理完一次位移缩放后，都会把待应用的剩余速度**强制清零**。
   - 这样光脚时（没有皮革靴支撑），每一拍只凭这一帧新产生的 `(0 - 0.08) × 0.98 = -0.0784` 重力微元再乘以 `1.5×` 向下沉，结果就是从头到尾以极慢的 **`-0.1176` 格/tick**（`-2.352` 格/秒）匀速下陷，不会像在空气中那样加速坠落，也没有摔落伤害。
3. **高空跌落细雪的落地表现**：
   - 无论光脚还是穿皮革靴，从高处掉进细雪**一律 0 摔落伤害**；其中穿皮革靴从高处重摔落入细雪时会向下陷进 1 格再被稳稳接住。
