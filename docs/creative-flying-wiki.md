# 基岩版创造飞行完全指南：加速、急停与竖直悬停（`1.26.51.01`）

创造飞行看起来只有"双击空格、按住前进"两件事，但它的手感里藏着两条完全不同的水平规则：
**按住方向键时，水平速度每 tick 只掉 `0.91`；一松手，第二 tick 起就直接掉到 `0.34125`**——
这就是"一松手就急停"的来源。竖直方向也有自己的脾气：上升与下降**不对称**，同时按跳和潜行
反而会原地锁死。

> **文档分工**：本文面向玩家、跑酷地图设计与手感调参，不写地址与组件编号；完整系统清单、
> 常量来源、逐 tick 原始数据见 [`notes/creative-flying-12651.md`](notes/creative-flying-12651.md)。
>
> **单位约定**：速度单位是 **格/tick**（`1` 秒 = `20` tick）。

## 一、一分钟结论速查

| 常见疑问 | `1.26.51.01` 实际表现 | 关键数值 |
| --- | --- | --- |
| **创造飞行最快多快？** | 水平稳态约 **`0.544` 格/tick（`10.9` 格/s）** | `v' = 0.91·v + 0.049` |
| **疾跑键有用吗？** | 有用，**精确 `2×`** | 稳态 `1.089` 格/tick（`21.8` 格/s） |
| **斜着飞（`W+A`）会更快吗？** | **不会**，只改方向 | 合成速度与直行相同 |
| **松手后多久停？** | 非常快：**第二 tick 起每 tick 只剩 `34%`** | 首 tick `0.91`，之后 `0.34125` |
| **上升多快？** | 约 **`0.375` 格/tick（`7.5` 格/s）** | `vy' = 0.6·vy + 0.15` |
| **下降多快？** | 约 **`0.55` 格/tick（`11` 格/s）**，比上升快 | `vy' = 0.6·vy − 0.22` |
| **同时按跳和潜行？** | **原地悬停**，竖直速度被清零 | `mPosDelta.y ≡ 0` |
| **贴着地面飞会变慢吗？** | **不会**，石面和蓝冰完全一样 | 摩擦/加速度逐位相同 |
| **在水里飞会变慢吗？** | **不会**，仍走飞行公式 | 与空中一致 |
| **迅捷/缓慢药水有用吗？** | **没用** | 水平/竖直都不变 |
| **落地会自动退出飞行吗？** | **不会**，触地后仍是飞行态 | 需再双击空格退出 |

## 二、水平：两套阻力，一个开关

### 1. 按住方向键：`0.91` 的"气动阻力"

飞行时每 tick 先加速、再乘阻力：

```
v ← 0.91 × v + 0.049
```

从静止起步，速度序列是 `0.049 → 0.094 → 0.134 → 0.171 → …`，大约 **`2` 秒**后贴近
`0.544` 的稳态。这个 `0.91` 与鞘翅滑翔、空中移动用的是同一个"空气阻力"值。

**疾跑键**把 `0.049` 直接翻倍（`0.098`），于是稳态也翻倍到 `1.089`——不是 `+30%` 的
地面疾跑加成，而是干净的 `2×`。斜飞时两个轴各分到一份加速度，合成模长仍是 `0.544`。

### 2. 松开方向键：第二 tick 起变成 `0.34125`

这是创造飞行最"反直觉"的一条：

| 松手后第几 tick | 速度还剩多少 |
| --- | --- |
| 第 1 tick | `91%` |
| 第 2 tick | **`34.1%`** |
| 第 3 tick | `11.6%` |
| 第 4 tick | `4.0%` |

也就是大约 **`4` tick（`0.2` 秒）** 就从满速滑到几乎停住。`0.34125` 不是某个单独写死的
"急停系数"，而是两个值相乘：

```
0.91（空中阻力） × 0.375（无输入时的额外阻尼） = 0.34125
```

那个 `0.375` 由竖直飞行控制顺带写入：**只要没有水平移动输入，它就会把水平与竖直的
"待执行位移"一起压到 `0.375` 倍**。因此：

- 按住前进/后退/左右（任意一个）→ 只吃 `0.91`，可以持续加速；
- 全部松开 → 从下一 tick 起吃 `0.91 × 0.375`；
- 只按跳跃或潜行（没有水平键）→ 水平仍然是 `0.34125`，**不会**让你滑得更远；
- 反过来，**按住水平键时松跳**，竖直方向只吃 `0.6`（不再乘 `0.375`），所以"边飞边刹车"比
  原地松手慢得多。

> **非键鼠输入**：触屏/手柄等模拟输入模式写进覆盖组件的是 `0.75` 而不是 `0.375`，
> 对应空闲水平阻力 `0.91 × 0.75 = 0.6825`。键盘/鼠标用不到这一档。

### 3. 贴地、蓝冰、水面都不影响

同一高度（脚离地 `0.5` 格）分别飞过石面与蓝冰，摩擦与加速度**逐位相同**；在水里飞行也与
空中完全一致。创造飞行不读脚下方块的摩擦系数，也不叠加水体阻力——想靠蓝冰"滑得更远"在
飞行状态下不成立。

## 三、竖直：上升、下降与悬停

### 1. 递推

```
上升（按住跳）：   vy ← 0.6 × vy + 0.15     稳态 +0.375
下降（按住潜行）： vy ← 0.6 × vy − 0.22     稳态 −0.550
同按跳 + 潜行：    vy ← 0                         （强制清零）
```

注意两点：

- **下降比上升快**（`0.55` vs `0.375`），不是对称的 `±0.15`；
- 竖直同样有 `0.6` 阻力，**松开竖直键后的第一 tick 还会再乘 `0.375`**，所以从 `+0.375`
  松手会直接掉到 `0.084`（`0.375 × 0.6 × 0.375`）。

### 2. 悬停

不按跳也不按潜行时，竖直速度在几 tick 内归零并保持 `0`——这就是"空中站住"。
同时按跳和潜行不是"抵消后慢慢下落"，而是**当拍直接把竖直位移清零**，所以可以当作
精确的悬停刹车用。

### 3. 落地不退出飞行

触地后 `flying` 仍然是真，`vy` 归零，人贴在面上。退出飞行只有两条路：**再双击一次空格**，
或失去 `MayFly` 能力（切游戏模式会重置能力，需要重新开）。

## 四、跑酷与地图设计上的用法

| 目标 | 做法 | 原因 |
| --- | --- | --- |
| **长距离平飞** | 全程按住前进；需要更快就按住疾跑键 | `0.91` 阻力下稳态 `0.544` / `1.089` |
| **精确停在点上** | 提前 **`2~4` tick** 松手 | 第二 tick 起只剩 `34%`，几乎没有"滑行缓冲" |
| **贴顶/贴地穿越** | 用潜行下降微调高度，松手即停 | 下降稳态 `0.55`，松手首 tick 再乘 `0.225` |
| **悬停观察/对齐** | 同时按跳 + 潜行 | 竖直位移强制为 `0` |
| **斜向接近** | `W+A`/`W+D` 即可 | 合成速度不变，只是方向 |
| **水中/蓝冰路线** | 不要指望飞行吃到地形加成 | 飞行忽略方块摩擦与液体阻力 |

一个实用的手感结论：**创造飞行的"刹车"比"油门"强得多**。加速要 `2` 秒左右才到稳态，
刹车只要 `0.2` 秒。跑酷图里设计"精准落点"时，把减速窗口按 `2~3` tick 估，而不是按
鞘翅或地面滑行的经验估。

## 五、与 Java 版的差异

| 维度 | Java | 基岩 `1.26.51.01` |
| --- | --- | --- |
| 松手后的水平阻力 | 仍 `0.91` | 首 tick `0.91`，之后 **`0.34125`**（急停） |
| 竖直加速度 | `±0.15`（对称） | **`+0.15` / `−0.22`（下降更快）** |
| 松手后的竖直阻尼 | `0.6` | `0.6`，空闲再乘 `0.375` |
| 同按跳 + 潜行 | 相加为 `0` | 强制清零（等价效果，实现不同） |
| 药水/水中影响 | 不直接影响飞行速度 | 同样不影响 |
| 落地退出飞行 | **是**（触地即取消飞行） | **否**（实测 `flying` 保持） |

Java 侧为机制对照，未在本机复测。

## 六、常见误解

- **"`0.34125` 是飞行专用常数"**：不是。它是 `0.91 × 0.375` 的乘积，`0.375` 是"无输入阻尼"，
  竖直方向也在用。
- **"按住跳跃能滑得更远"**：不能。水平只看有没有水平输入。
- **"贴蓝冰飞能加速"**：不能，飞行不读方块摩擦。
- **"疾跑飞行是 `1.3×`"**：不是，是 `2×`；`1.3×` 是地面疾跑的速度属性修饰。
- **"落地就退出飞行"**：基岩版不会，`flying` 会一直保留到你再次双击空格；Java 版则会在触地时自动取消。
