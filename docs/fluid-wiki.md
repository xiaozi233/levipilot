# 水与岩浆中的运动（基岩版 1.26.51.01）

玩家在液体里的运动可以拆成四条彼此独立的规则：**竖直递推**、**水平阻力**、**流动推力**、
**游泳视角控制**，外加一条判定规则决定"多深才算在水里"。下面所有数值都同时满足
1.26.51.01 的反编译结果与逐 tick 实测。

记号见表；全文速度单位均为**格/tick**，$v'$ 表示下一 tick 的速度。

| 符号 | 含义 | 单位 |
|---|---|---|
| $v$ | 速度 | 格/tick |
| $v_y$ | 竖直速度，向上为正 | 格/tick |
| $v_{x,z}$ | 水平速度分量 | 格/tick |
| $v_\infty$ | 稳态速度（递推的收敛值） | 格/tick |
| $d$ | 每 tick 乘在速度上的阻力系数 | 无量纲 |
| $g$ | 每 tick 直接加到速度上的重力项 | 格/tick² |
| $\rho$ | 水平阻力系数 | 无量纲 |
| $\theta$ | 俯仰角，低头为正 | 弧度 |
| $\tau$ | 俯仰角对应的目标竖直速度 $-\sin\theta$ | 无量纲 |
| $k$ | 游泳平滑系数（1.3 / 0.085 / 0.06） | 无量纲 |
| $k_f$ | 流动推力系数（0.014 / 0.0035 / 1.0） | 格/tick |
| $\ell$ | 液位，取值 0–7 | 1/8 格 |
| $\hat d_i$ | 四个水平邻接方向的单位向量 | 无量纲 |
| $\hat u$ | 流推的归一化方向（含 $(0,-6,0)$ 竖直偏置） | 无量纲 |
| $L$ | 深海行者等级，上限 3 | 级 |

## 速览

| 问题 | 答案 |
|---|---|
| 掉进水里不按任何键会怎样 | 以 **0.5 格/s** 缓沉，最终停在池底 |
| 怎么上浮 | 按住跳跃键：水 **+0.175 格/tick**（3.5 格/s），岩浆 +0.04 |
| 怎么快速下潜 | 进入游泳态后低头，最高 6.3 格/s |
| 一格深的水会拖慢多少 | 干地速度的 43–60%；浅于 0.4 格完全无影响 |
| 岩浆和水的区别 | 水平阻力 0.5（每 tick 减半）、下沉更快、不按跳跃键永远浮不起来 |

---

## 1. 竖直速度

### 1.1 三条递推

统一形式（$v'$ 为下一 tick 速度，$d$ 为阻力、$g$ 为重力项）：

$$v' = d\,v + g \quad(\text{液体}), \qquad v' = d\,(v+g) \quad(\text{空气})$$

| 介质 | 递推 | 阻力 $d$ | 重力项 $g$ | 终速 $v_\infty$ |
|---|---|---|---|---|
| 空气 | $v' = 0.98\,(v - 0.08)$ | 0.98 | −0.08 | −3.92（−78.4 格/s） |
| **水** | $v' = 0.8\,v - 0.005$ | 0.8 | −0.005 | **−0.025（−0.5 格/s）** |
| **岩浆** | $v' = 0.5\,v - 0.02$ | 0.5 | −0.02 | **−0.04（−0.8 格/s）** |

液体的顺序是**先乘阻力、再加 $g$**；空气相反（先加重力、再乘阻力）。两种写法不能互换：
水若写成 $0.8(v+g)$ 需要 −0.00625 的重力，代码里不存在这个常量。

水与岩浆从静止起的逐 tick 序列与递推逐位一致：

- 水：$0,\ -0.005,\ -0.009,\ -0.0122,\ -0.01476,\ -0.01681,\dots$
- 岩浆：$0,\ -0.02,\ -0.03,\ -0.035,\ -0.0375,\ -0.03875,\dots$

液体里逐 tick 位移约等于 $v_y$ 本身（实测比值 1.0065），不需要地表那套 0.546 换算。

### 1.2 按住跳跃键：上浮

液体判定通过时，跳跃键在阻力之后给 $v_y$ 加 **+0.04**，同一条递推就翻成上升：

| 液体 | 有效 $g$ | 终速 | 到速时间 |
|---|---|---|---|
| 水 | $0.04-0.005=+0.035$ | **+0.175 格/tick（3.5 格/s）** | 约 24 tick |
| 岩浆 | $0.04-0.02=+0.02$ | **+0.04 格/tick（0.8 格/s）** | 约 12 tick |

从水的 −0.025 稳态起步：$0.015,\ 0.047,\ 0.0726,\ 0.0931,\ 0.1095,\dots,\ 0.1742$。

- 与视角无关。水里唯一稳定的上升手段就是按住空格。
- 按下后第一个 +0.04 会晚 **2–4 tick** 出现（输入队列 + 液/气物理切换），不是没生效。
- 贴水面会"探出又落回"：脚出水 0.4 格后判定盒离开液体、切回空气重力，
  实测 $v_y$ 在 $+0.17$ / $-0.2$ 间交替，脚部稳定在液面下约 0.6 格。

## 2. 水平速度

### 2.1 阻力

每 tick 水平速度乘一个阻力系数 $\rho$：

$$v_{x,z}' = \rho\,v_{x,z}$$

| 情形 | $\rho$ |
|---|---|
| 疾跑（SPRINTING 置位） | 0.9 |
| 默认 | 0.8 |
| 深海行者 $L$ 级（$L\le3$，离地时 $L$ 减半） | $0.8 + (0.546-0.8)\,L/3$ |

- 水阻力**替代**地面摩擦，不叠乘：顺流推力的平衡速度 $0.014/(1-0.8)=0.070$ 实测逐位吻合
  （若叠乘地面摩擦应为 0.025）。
- 深海行者 III 接地时阻力回到 0.546，等于干地；实测涉水 0.098 → 0.210 格/tick（**2.15×**）。
- `SwimSpeedMultiplier > 1`（海豚的恩惠一类）时跳过向 0.546 的混合。
- 松开疾跑后前两拍仍乘 0.900，之后回到 0.80（标志约维持 2 tick）。

### 2.2 实测速度

| 状态 | 速度 |
|---|---|
| 干地疾跑 | 0.28 格/tick = **5.6 格/s** |
| 1 格深水中疾跑前进 | 0.12–0.17 格/tick = **2.4–3.4 格/s** |
| 逆全强度流前进 | 净速约 **1 格/s**，甚至被推倒退 |
| 顺流不动 | 0.070 格/tick = **1.4 格/s** |

1 格深水里玩家会上下浮动（脚离地 0.4–0.8 格、`onGround=false`），速度随之起伏。

### 2.3 疾跑起步的延迟

从静止起步（t0 = 按下 W、`vz=0` 的那一 tick），水里的正常形态：

| Tick | t1 | t2 | t3 | t4 |
|---|---|---|---|---|
| 正常行走 | 0.01959 | 0.03528 | 0.04782 | 0.05786 |
| 手动同按（常规相位） | 0.01959 | 0.03528 | **0.05133** | 0.06580 |
| 疾跑键已在采样前按住（早相位） | 0.01959 | **0.03723** | 0.05310 | 0.06738 |

- **常规相位前两个移动 tick 与走路相同，第三个才切 0.9；早相位只经历一个走路 tick，第二个就切。** 差别是按键落在采样点的哪一侧，不是阻力读旧位。
- 0.9 的延迟来自**记录位（客户端 sprint 状态）→ 约 2 tick 状态链 → ADF 写位**；同一 tick 内 ActionSprintTrigger 写在阻力之前，水阻力读的是**新位**。不是“阻力先算、疾跑位后写”。
- 计时从**前进被采样**开始，不是从按疾跑键开始；输入晚到一拍（注入常见）整体顺延为
  `0.01959/0.03528/0.04782/0.06262`。
- **平地**只差一拍：状态一变，下一 tick 加速度就乘 1.3（0.098 → 0.181）；地面不经过 ADF 位。
  乘 1.3 的实现在属性层：`Actor::setSprinting` 给移动速度属性挂上 `"Sprinting speed boost"`
  modifier（amount 0.3、`MULTIPLY_TOTAL`，重算时 `(0.3+1)×0.1=0.13`），代码里并没有 1.3
  这个常数。
- **站着不动按疾跑键不会置位疾跑**：sprint 状态从第一次前进移动才开始，所以"提前按住"
  无法预置。

### 2.4 流动推力

每 tick 沿归一化方向加固定速度：

$$\hat u = \mathrm{normalize}\Bigl(\mathrm{normalize}\bigl(\textstyle\sum_{4\ \text{邻}}(\ell_i-\ell_{\text{self}})\,\hat d_i\bigr) + (0,-6,0)\Bigr),
\qquad \vec v \mathrel{+}= k_f\,\hat u$$

其中 $\ell_i$ 为第 $i$ 个水平邻接方块的液位、$\ell_{\text{self}}$ 为玩家所在方块的液位，
$\hat d_i$ 为由自身指向该方的方向单位向量，$\hat u$ 为归一化后的推力方向。

| 液体 | $k_f$ |
|---|---|
| 水 | 0.014 |
| 岩浆 | 0.0035 |
| 其他 | 1.0 |

- 推力加到**三个分量**上，包括 $v_y$；$(0,-6,0)$ 是"无侧向流"时的偏置。
- 静水没有液位差，分支不执行，因此完全没有推力。

## 3. 游泳：视角控制竖直速度

进入游泳态（SWIMMING）后，竖直速度不再由重力主导，而是被俯仰角"瞄准"：

$$\tau=-\sin\theta,\qquad
k=\begin{cases}1.3 & \text{飞行中}\\ 0.085 & \tau<-0.2\\ 0.06 & \text{其他}\end{cases},\qquad
v_y'=0.8\,v_y + k\,(\tau-0.8\,v_y)$$

$$v_\infty=\frac{k\tau}{0.2+0.8k}
=\begin{cases}0.317\,\tau & k=0.085\\ 0.242\,\tau & k=0.06\end{cases}$$

其中 $\theta$ 为俯仰角、$\tau=-\sin\theta$ 是当前视角对应的目标竖直速度（无量纲），
$k$ 为平滑强度（1.3 飞行 / 0.085 陡俯 / 0.06 其余），$v_\infty$ 为收敛到的稳定竖直速度。

| 俯仰（低头为正） | 实测 $v_\infty$ | $0.317\tau$ |
|---|---|---|
| 87° | −0.316 | −0.3166 |
| 60° | −0.275 | −0.2745 |
| 30° | −0.159 | −0.1586 |
| 10°（$k=0.06$） | −0.044 | −0.0420 |
| 0° | 0 | 0 |

- 低头下潜最高 0.317 格/tick（**6.3 格/s**），是被动下沉的 12.7 倍 —— "想速沉就低头"。
- 头还在水里时抬头也会上升：pitch −30° 实测稳态 $+0.121=0.242\tau$。
- **只有平视且头露出水面**才把 $v_y$ 压成 0（踩水）；头在水中始终走平滑。
- 进入游泳态需要**疾跑状态**：深水（离底 ≥2–3 格）里前进 + 疾跑，4–8 tick 置位；
  只前进不会进。松键后 5–15 tick 退出；站底约需 20 tick，或先按住跳跃离底。
- 水中抵墙 + 前进：先悬停几 tick，随后以约 $+0.17$ 格/tick **沿墙上浮**出水面。

## 4. 多深才算"在水里"

判定用的是玩家 AABB **内缩**后的盒子：X/Z 各缩 0.1，Y 缩 0.4。
对 1.8 格高的玩家，检测区间是 $[\text{脚}+0.4,\ \text{脚}+1.4]$。

- 水深 **< 0.4 格（液位 ≤3）完全没有液体物理**：不减速、不受流推、不下沉。
- 水深 0.4–1.4 格（头出水）时，阻力与流推已全额生效。
- 全身浸没需要水深 ≥ 头顶 1.4 格。
- 液体盒首次相交的那一 tick 仍按空气结算，下一 tick 才切液体物理。
- 判定只看流体谓词，不看方块 id：源水、流动水、waterlogged 行为一致。

## 5. 岩浆

| 项 | 值 |
|---|---|
| 竖直 | $v'=0.5v-0.02$ ⇒ 终速 −0.04 格/tick |
| 水平 | 每 tick ×0.5 |
| 上浮 | 只有按住跳跃键：+0.04 格/tick |
| 流动推力 | 0.0035（水的 1/4） |
| 静置 | 任意深度持续下沉，不会漂浮 |

不输入会一路沉到池底；水平动量每 tick 减半，冲进岩浆会迅速停住，
持续前进的稳态约 0.039 格/tick（远慢于步行）。

## 6. 实用结论

- **落水不会瞬停**：每 tick ×0.8，−0.78 到 −0.25 约 6 tick，制动行程 2–2.5 格。
- **水很"浮"**：不操作只以 0.5 格/s 缓沉，回水面很从容；想快就低头，想上升就按空格。
- **一格深的装饰水道**只有干地速度的 43–60%；浅于 0.4 格则完全无影响。
- **水道是变速带**：逆流净速约 1 格/s，顺流白送 1.4 格/s。
- **岩浆是粘住的地形**：下沉快、水平几乎停死，没有跳跃键就上不来。
- **深海行者是涉水的最优解**：III 级接地时把水阻力修回干地值（2.15×）。
