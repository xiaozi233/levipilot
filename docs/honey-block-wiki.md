# 基岩版蜂蜜块机制指南（`1.26.51.01`）

蜂蜜块是跑酷图里最“黏人”的方块：**只要干燥实体与它的整格单元有重叠**，水平待执行位移就会被按块数逐个乘以 **`0.4`**；贴墙下落时竖直位移被钳在 **`-0.12` 格/tick** 匀速下滑；站在顶面会**明显掉速、跳不高**；摔上去则走**摔落距离减半**。基岩版与 Java 版有几项直接影响手感的区别：**碰撞箱顶面满格 `1.0`**、滑落比 JE 快 `2.4` 倍、摔落减伤是“距离 `×0.5`”而不是“伤害 `×0.2`”，且**水中完全跳过蜂蜜块贴墙效果**。

> **文档分工**：本文面向玩法理解、跑酷线路设计与 JE/BE 对照，略去反编译地址与组件编号；完整写入点、常量地址、系统注册顺序与逐 tick 原始数据见 [`notes/honey-block-12651.md`](notes/honey-block-12651.md)。方块碰撞箱总表见 [`notes/block-collisions-12651.md`](notes/block-collisions-12651.md)，减速方块家族见 [`slowing-blocks-wiki.md`](slowing-blocks-wiki.md)。
>
> **单位约定**：速度默认 **格/tick**（`1` 秒 = `20` tick），括号内附 **格/秒**；高度均指脚底相对目标表面的差值。

## 二、外形与碰撞箱：一个“矮不下去”的缩水盒

Java 版的蜂蜜块顶面比整格低 `0.0625`（`0.9375` 高），基岩版不是：

- **水平**：每侧缩 `0.0625`，碰撞宽 `0.875 × 0.875`；
- **竖直**：从 `y = 0` 到 **`y = 1.0`**，实打实的满格。

这个差别带来两个直接结果：

1. **站在顶面完全平齐，不会“陷下去”**：脚底站位是 `block.y + 1.0`；
2. **判定是否“进入蜂蜜块”看整格单元，不看缩水碰撞盒**：玩家半宽 `0.3`，贴着侧墙站立时中心在缩水面外 `0.3` 格，虽然与缩水碰撞盒重叠为 `0`，却刚好压进所在**整格单元 `0.0625` 格**——所以一贴墙立刻被吸住。实测紧贴墙面走速被压到 `0.0994`，只要再外移 `0.07` 离开整格单元，速度瞬间恢复全速 `0.2150`。

## 三、贴墙滑落与 `0.4` 减速的真实规律

### 1. 缩放和钳位并不挑“状态”

每当干燥（不在水中）的玩家碰撞箱与某个蜂蜜块所在整格有正重叠时，系统就会直接对该方向待执行位移做两件事——**完全不管你是否在地面、向上跳还是向下掉**：

```text
① 水平待执行位移 × 0.4   （碰几块乘几次，即 0.4^n）
② 竖直待执行位移钳到 max(原来的值, -0.12)
```

实测三条不同姿态贴墙的表现如下（对照组为同地形无墙/石面）：

| 场景 | 贴墙表现 | 对照组 | 结论 |
| --- | --- | --- | --- |
| **地面贴 `1` 层墙走** | `0.1172` 格/tick | 石面 `0.2159` | 站在地面同样被削弱 |
| **地面贴 `2` 层墙走** | `0.0828` 格/tick | 石面 `0.2159` | 多覆一层叠乘更多次 |
| **贴墙斜跑起跳（上升段）** | `0.0312` 格/tick | 开阔 `0.2156` | 向上跳一样被按 `0.4` 缩放 |
| **贴墙下落** | 稳态 **`-0.12` 格/tick**（`2.4` 格/s） | 离墙坠落 `-0.8439` | 瞬间锁死终端速度不再加速 |

> **实战提醒**：想“擦着蜂蜜墙全速跑过”必须**完全不压进蜂蜜格**；只要身体压进哪怕一点点，哪怕在平地上走也会立刻半速以上暴跌。

### 2. 清零摔落距离与特效的“真实滑落门”

代码里真正的“贴墙滑落”条件（比地面 `0.9375` 门限）其实**只管两件事**：**清零摔落距离**和**触发滑落音效/粒子**，不管 `0.4` 与 `-0.12`：

```text
① 正在下落（竖直待执行位移 < 0）
② 玩家身体基准（脚底 + 1.62 格）<= 方块 y + 0.9375
   └─ 换算成脚底：脚底 <= 方块 y - 0.6825（蜂蜜块必须在脚底上方约 0.68 格以上）
③ 水平位于墙面外侧（与方块中心距 > 0.5×体宽 + 0.43125 = 0.73125）
```

因此：
- 从高处经过**单块悬空蜂蜜**时，身体只在一瞬间低于方块 `0.68` 格、清零一次摔落距离，离开后继续累计约 `9.3` 格落差，落地依然摔伤 **`6` 点（`3` 颗心）**；
- 只有沿着**连续高墙**一路贴到底（每个 tick 都在清零摔落距离），着陆伤害才会是 **`0`**（对照同 `15` 格无墙落差伤害 `12`）。

## 四、贴多块：`0.4^n` 逐块连乘

如果身体同时跨在多个蜂蜜单元上，`0.4` 会**按同拍命中的块数逐块连乘**。当仅压到不同数量且不再输入按键自由滑行时，空中每拍原本只保留空气阻力 `0.91`，加上蜂蜜块后相邻拍水平位移比值为 $0.91 \times 0.4^n$：

| 同拍命中的蜂蜜块数 `n` | 拓扑例子 | 实测相邻拍比值 | 理论 $0.91 \times 0.4^n$ |
| --- | --- | --- | --- |
| `1` | 单块侧贴 | **`0.3641`** | `0.364` |
| `2` | 垂直上下 `2` 块 / 水平跨缝 `2` 块 / 内角 `2` 块 | **`0.1449`** | `0.1456` |
| `4` | 水平接缝 + 上下双层（理论极端 `0.4^4`） | 进入 `4` 个条目、触发钳位 | `0.0233` |

- **保速擦边**：若必须擦墙，尽量避免站在两块接缝上或贴双层高墙；
- **急速制动**：主动对准水平接缝 + 双层墙，`1~2` 拍内水平余速就会被按到几乎归零。

## 五、顶面机制：`0.8` 滑度、粘滞、起跳削弱与黏液块对照

### 1. 站上顶面走路与潜行（与黏液块完全一致）

站在蜂蜜块或黏液块顶面时，两个方块共有相同的两套机制：**`0.8` 滑度**（使地面加速度按 $(0.6 / 0.8)^3$ 下降）以及额外乘数 $k = 0.4 + 0.2|dy|$（起跳 `dy >= 0.1` 时跳过）。**潜行都会跳过 $k$ 乘数，但仍保留 `0.8` 滑度减速**——在顶面走和潜行上，蜂蜜块与黏液块表现**逐位一致**：

| 脚下方块 | 普通走路（格/tick） | 相对石面 | 潜行走（格/tick） | 相对石面潜行 |
| --- | --- | --- | --- | --- |
| 石头 | `0.2159` | `100%` | `0.0648` | `100%` |
| **蜂蜜块** | **`0.0593`** | **`27.5%`** | **`0.0456`** | **`70.4%`** |
| **黏液块** | **`0.0593`** | **`27.5%`** | **`0.0456`** | **`70.4%`** |

### 2. 起跳只有 `60%`（以及站边恢复）

蜂蜜块在方块属性里带有“抑制跳跃”标记（石头与黏液块都没有），导致起跳瞬间 `(0.42 + 跳跃提升)` 整体乘 **`0.6`**（无药水时 `0.42 → 0.252`）：

| 起跳位置 | 峰值升幅 | 结论 |
| --- | --- | --- |
| 石头 / 黏液块顶面 | `1.252` 格 | 正常全高 |
| **蜂蜜块顶面中心** | **`0.514` 格** | 跳不上 `1` 格台阶 |
| **脚底中心刚出蜂蜜格（台边外 `0.15` 格，AABB 仍被托住）** | **`1.252` 格** | 看脚底中心格，悬边即可恢复全力跳！ |

## 六、摔落伤害：距离 `×0.5`（不是 JE 伤害 `×0.2`）

直接从高处摔到蜂蜜块顶面时，引擎将**摔落距离直接乘 `0.5`** 再代入普通摔伤计算，而不是把最终伤害乘 `0.2`：

| 垂直落差 | 落到石头伤害 | 落到蜂蜜块伤害 | 折算逻辑 $\lceil 0.5h - 3 \rceil$ |
| --- | --- | --- | --- |
| `10` 格 | `7`（`3.5` 心） | **`2`（`1` 心）** | 按 `5` 格摔算 |
| `15` 格 | `12`（`6` 心） | **`5`（`2.5` 心）** | 按 `7.5` 格摔算 |
| `20` 格 | `16`（`8` 心） | **`7`（`3.5` 心）** | 按 `10` 格摔算 |

越从高处直摔，基岩版越比 JE 疼（JE `20` 格不到 `2` 心，BE 要掉 `3.5` 心）。高空保命务必贴墙滑落，不要直接往蜂蜜顶上砸。

## 七、特殊姿态边界

| 姿态 | 水平 `0.4` 缩放 | 竖直 `-0.12` 钳位 | 实测说明 |
| --- | --- | --- | --- |
| **潜行贴墙** | 生效 | **生效**（`-0.12`） | 潜行仅跳过顶面乘数，不免滑落 |
| **创造模式（未飞行）** | 生效（地面走 `0.1019`） | **生效**（`-0.12`） | 与生存完全一致 |
| **创造模式飞行** | **仍然生效**（贴墙 `0.0502` vs 开阔 `0.3748`） | **不生效**（下降可达 `-0.34`） | 飞行只免竖直钳位，照样按 `0.4` 刹水平速度 |
| **水中贴墙** | **完全跳过（免疫）** | **完全跳过** | 静水池贴墙与开阔水域同拍 `0.0652 → 0.0679 → 0.0700` 逐位一致 |

## 八、Java Edition 核心差异总表

| 维度 | Java Edition | Bedrock `1.26.51.01` | 跑酷影响 |
| --- | --- | --- | --- |
| **碰撞箱高度** | `0.9375` | **`1.0`** | BE 顶面齐平，站在上面不会误触滑落 |
| **滑落终端速度** | `-0.05` 格/tick | **`-0.12` 格/tick** | BE 下滑快 `2.4` 倍，`10` 格墙约 `1.7` 秒到底 |
| **水平 `0.4` 适用范围** | 贴墙叠加 `0.4^n` | **无条件按重叠块数叠加 `0.4^n`**（含地面/上升/创造飞） | BE 擦墙走路和起跳一样立刻掉速 |
