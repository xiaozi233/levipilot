## 二、碰撞箱、滑度与方块属性

### 1. 虚表与工厂

- `[常量]` `HoneyBlock::$vftable = 0x14e999b30`，132 槽；`slot[4]=getCollisionShape 0x1466ba020`、`slot[117]=onStandOn 0x1466ba420`、`slot[125]=getBounciness 0x1409276f0`、`slot[131]=entityInside`。
- `[代码]` 工厂 `0x14c6e7802..0x14c6e786b`：分配 `0x378`，`BlockType` 构造（id `0x1db=475`），写虚表 `0x14e999b30`，`+0x15C` 与 `+0x178` 均为 `0x3f4ccccd`（`0.8f`），`+0x162=3`。
- `[实测]` `block_shapes`：`friction = 0.800000011920929`。

### 2. 碰撞盒常量

`[代码]` `getCollisionShape`（`0x1466ba020..0x1466ba0da`）只做一次 AABB 拼装；六个全局量由 `0x1466c9770` 写入：

- `[常量]` `.rdata 0x14e842580` 的 16 字节 = `{0.0625, 0, 0.0625, 0.9375}` → `min.x/min.y/min.z/max.x`；
- `[常量]` `movabs 0x3f7000003f800000` → `max.y = 1.0f`、`max.z = 0.9375f`。

因此单盒为 **`[0.0625, 0, 0.0625] .. [0.9375, 1.0, 0.9375]`**：水平每侧缩 `0.0625`，**顶面满格 `1.0`**。

> JE 的 `0.9375` 顶面在 BE 只作为滑落几何门的上沿，不是碰撞高度。

### 3. `BlockLegacy+0x130` 的 `PreventsJumping` 位

`[代码]` 起跳系统读取 `BlockLegacy+0x130` 并测试 bit30（`0x40000000`）。

`[实测]` 运行期读方块类型字：

| 方块 | `BlockType+0x130` | bit30 |
| --- | --- | --- |
| `minecraft:honey_block` | `0x40020000` | **置位** |
| `minecraft:stone` | `0x00040000` | 未置位 |
| `minecraft:slime` | `0x00060000` | 未置位 |

`[推断]` 该位来自方块定义表（数据驱动）而非工厂内联写入；工厂只写 `0.8f` 与 `+0x162=3`。因果链已由“起跳 worker 测该位 + 蜂蜜运行期确有该位 + 实测 `0.6×`”闭合。

## 三、组件流与“判定盒”

### 1. 写入与条目格式

`[代码]` `EntityInsideSystem` 的逐块回调 `0x1463bf8d0..0x1463c00ba` 按方块类型字分派；蜂蜜分支为 `0x1463bfc1e`（比较 `0x2c975e4949d832f7`）→ `0x1463bfdf8`：

- 取/建组件 `0xc83bbc35`（`0x1463bf010`）；
- 追加 24 字节条目：`BlockPos`（`+0x00..0x0B`）+ 填充 + `Block const*`（`+0x10`）；
- 追加语句在 `0x1463bfe75`（`[rdx+0x10]=rdi`、`[r15+8]+=0x18`），**没有**再做相交判断——相交由调用者的体素遍历保证。

### 2. 组件是 tick 内瞬态

`[实测]` 在玩家贴墙（滑落生效、`vy=-0.12`）时：

- `ecs_component(runtime_id, 0xc83bbc35)` → `component_not_found`；
- 对同一 id 的 `record` watch（`+0x08/+0x10`）→ 全为 `None`；
- 同实体的 `AABBShape 0xbac1b3cf`、`FallDistance 0xce6b34f6` 均可正常读取。

因此该组件在 tick 结束前已被清理，**无法通过 ECS 快照或 watch 读取条目数**。本轮改用“整格单元相交的几何 `n` + 行为判定”，并用边界实测校准判定盒（见 §3.3）。

### 3. 判定盒：与整格单元的正重叠

`[实测]` 同一面 2 格高蜂蜜墙、同一 z、只改贴墙距离，沿墙走 12 tick：

| 位置 | 与墙单元的关系 | 稳态 `Δz` |
| --- | --- | --- |
| `x = 609.7625`（贴面） | AABB 压进单元 `0.0625` | **`0.099396`** |
| `x = 609.6925`（离面 `0.07`） | AABB 与单元无重叠 | **`0.214996`** |

`[代码]` 缩水碰撞盒的面在 `610.0625`，贴面时与碰撞盒的重叠为 **0**，但 `0.4` 仍然生效；因此判定盒覆盖到**整格单元边界**（`AABB.max > cell.min` 即命中），不是缩水盒。

### 4. 系统注册顺序

`[代码]` 同一初始化函数 `0x1468353c0..0x14683ab80` 内先注册 `EntityInsideSystem`（`0x146838546`，对象 `0x14e98a910`，tick `0x1463c0410` / `0x1463c0f90`），后注册 `InsideHoneyBlockSystem::fireEventsSystem`（`0x14683913a`，vt `0x14eb40470`，tick `0x14c600670` / `0x14c600df0`）。同函数内 `push_back`、正序遍历（见 [`tick-order-12651.md`](tick-order-12651.md) §8），因此写入/消费的 `EntityInsideSystem` 先于只做效果与清理的 `fireEventsSystem`。

## 四、滑落的真实控制流

### 1. 每条目无条件缩放

`[代码]` `0x1463af270..0x1463af3a5`（批量 tick 回调）与 `0x1463c73f0..0x1463c7645`（单实体 tick）循环遍历 `0xc83bbc35` 的每个条目：

```text
mpd.x *= 0.4f                       // 0x1463af303 / 0x1463c7594
mpd.y  = max(mpd.y, -0.12f)         // maxss，0x1463af309 / 0x1463c759a
mpd.z *= 0.4f                       // 0x1463af30f / 0x1463c75a0
```

这段在循环开头，**不受** `onGround`、`mpd.y` 符号、方块高度或水平距影响。`[常量]` `0.4f=0x14e602290`、`-0.12f=0x14e98a5d0`。

`[实测]` 三条独立证据：

| 场景 | 输入/状态 | 结果 |
| --- | --- | --- |
| 地面贴墙走（`on_ground=True`，`mpd.y=-0.0784`） | 沿墙 +Z | 石面 `0.215881` → 1 层墙 `0.117175`、2 层墙 `0.082825` |
| 贴墙起跳的**上升**段（`mpd.y>0`） | 同角度斜跑 + 跳 | 开阔 `0.215637` → 贴墙 `0.031209`（`0.1447×`） |
| 贴墙下落 | 前进压墙 | 稳态 `vy = -0.119999`（31 拍） |

### 2. 几何门：只清 `FallDistance` 与播效果

`[代码]` 乘算之后（`0x1463af315..0x1463af386`）的判断：

```text
mPos.y <= block.y + 0.9375
&& mpd.y < 0
&& ( |block.x + 0.5 - mPos.x| > 0.5 * AABBShape.mBBDim.x + 0.43125
  || |block.z + 0.5 - mPos.z| > 0.5 * AABBShape.mBBDim.x + 0.43125 )
```

命中时跳到 `0x1463af2d0: mov dword ptr [r9], 0`。`[代码]` 该回调的第 4 个参数由 `0x1463c5840` 的 `r9` 传入，来源是 `0x1463c4db0` 视图元组的第 4 项 **`FallDistanceComponent 0xce6b34f6`**；同一判断也用于 `InsideHoneyBlockSystem::fireEventsSystem` 调 `triggerSlidingDownEffects`（`0x14c600950`）。

- `[代码]` `mPos.y` 是 `StateVectorComponent::mPos.y`（`+0x04`），`[实测]` 其与脚底差为 `1.6200101`；于是竖直条件等价于 **`feet_y <= block.y - 0.6825`**，即蜂蜜块必须高于脚底约 `0.68` 格（胸/头高度）。
- `[代码]` 水平阈值 `0.5×0.6+0.43125 = 0.73125`；贴面时 `|dx| = 0.7375 > 0.73125`，OR 条件成立。
- `[实测]` 摔落 15 格（石地）三组对照：

| 场景 | 伤害 | 解释 |
| --- | --- | --- |
| 高蜂蜜墙（`-60..-50`，持续贴墙滑落至 `end_y=-60.0`） | **`0`** | 每个 tick 都命中清零，完整着陆 `fallDistance=0` |
| 单块蜂蜜（`y=-50`，只经过 1~2 tick，着陆 `-60.0`） | **`6`** | 窗口内清零一次，之后从 `0` 重新累计约 `9.3` 格 |
| 无墙（着陆 `-60.0`） | **`12`** | 基准 `15-3` |

### 4. 顺序与终端速度

`[实测]` 从墙中部（`feet=-54`）起落，第一拍 `mpd_y` 就是 `-0.12`，31 拍保持 `-0.119999`；若钳位在重力之前，稳态应为 `(-0.12-0.08)×0.98≈-0.196`。
`[实测]` 离墙 `0.12` 格的无输入对照最小 `vy=-0.84391`，排除全局重力改动。

## 六、顶面：`0.4 + 0.2|dy|`、`0.8` 滑度与黏液块对照

### 1. 代码

`[代码]` `HoneyBlock::onStandOn`（`0x1466ba420..0x1466ba5b6`）：

```text
if (ADF(0xc67426f3) & 2) return            // Sneaking
mpd = StateVector(0x1b5d5238)
if (mpd.y >= 0.1f) return
k = 0.4f + 0.2f * |mpd.y|
mpd.x *= k;  mpd.z *= k
```

`[常量]` `0.4=0x14e602290`、`0.2=0x14e6ae454`、`0.1=0x14e6ae460`、绝对值掩码 `0x14e5c6380`。滑度 `0.8f` 写在工厂 `+0x15C/+0x178`。

### 2. 实机：蜂蜜与黏液逐位相同

`[实测]` 同尺寸平台、同 34 tick 行走（末段 `Δz`）：

| 场景 | 走路 | 潜行走 |
| --- | --- | --- |
| 石面 | `0.215881` | `0.064758` |
| 蜂蜜块 | **`0.059265`** | **`0.045593`** |
| 黏液块 | **`0.059265`** | **`0.045593`** |

- 走路比：蜂蜜/黏液均为石面的 **`0.2745`**；潜行走比均为 **`0.7041`**。
- `[实测]` **潜行不能免减速**：石面潜行 `0.064758` → 蜂蜜潜行 `0.045593`（`70.4%`）。

## 七、起跳 `0.42 → 0.252`（`0.6×`）

`[代码]` `JumpFromGroundSystem` 的 worker `0x1495e9200..0x1495e9515`：

1. `0x1495e925b..0x1495e9293` 取脚底格 `(floor(x), floor(aabb.min.y), floor(z))`；
2. `0x1495e92b0..0x1495e92bd` 读 `BlockLegacy+0x130`，`test ecx, 0x40000000`；命中 → `0x1495e9331`；
3. 未命中则看下方一格（`0x1495e92d5..0x1495e9304`，`test byte ptr [rax+0x133], 0x40`，同一个 bit30）；
4. 命中时 `0x1495e9348: movss xmm6, [0x14e6ae498]` = **`0.6f`**，否则 `xmm6 = 1.0f`（`0x1495e9327`）；
5. `0x1495e9367` 取 `0.42f`（`0x14e85af30`）并加跳跃提升；
6. `0x1495e93f2: mulss xmm0, xmm6` —— 整个 `(0.42 + JumpBoost)` 乘 `0.6`，再 `maxss` 写入 `mpd.y`（`0x1495e93f6`）。

`[实测]` 同输入（2 tick 跳跃）：

| 落脚面 | 升幅 | 反解初速 |
| --- | --- | --- |
| 石面 | `1.252197` | `0.42` |
| 蜂蜜顶面 | **`0.514`** | **`0.252`** |
| 黏液顶面 | `1.252197` | `0.42` |
| 蜂蜜台面外 `0.15` 格（脚底中心已出格） | `1.252197` | `0.42` |

离散弹道 `v ← (v-0.08)×0.98`、`y += v` 自 `0.252` 的峰值正是 `0.514`。边缘恢复说明判定看**脚底中心所在格**，不是 AABB 是否还搭在台面上。

## 八、摔落：距离 `×0.5`

`[代码]` 工厂 `0x14c6e7872` 传给 `0x1466b9bb0` 的回调 `0x1466b9f10..0x1466ba01c` 就是 **`HoneyBlock::onFallOn`**：

- `0x1466b9ff1: movss xmm1, [rsi+0x28]` —— 事件的摔落距离；

- `0x1466b9ffe: movss xmm2, [0x14e5a7060]` —— 伤害乘数 `1.0f`；

| 落差 | 石面伤害 | 蜂蜜伤害 | `ceil(0.5h-3)` |

| `15` | `12` | **`5`** | `5` |
| `20` | `16` | **`7`** | `7` |

`[实测]` 从墙顶下方 `0.5` 格（`-52.5`）贴墙滑到 `-60`（`7.5` 格），着陆伤害 **`0`**。

## 九、特殊姿态

### 1. 潜行贴墙滑落

`[实测]` `forward+sneak` 贴墙下落 26 tick：稳态 `vy=-0.119999`。`onStandOn` 的 Sneaking 分支只跳过顶面水平乘数，不影响滑落钳位。

### 2. 创造模式（未飞行）

`[实测]` `gamemode creative`、不飞行：

- 地面贴墙走：稳态 `Δz=0.101908`（生存同场景 `0.082825`，同受 `0.4`）；
- 贴墙下落：稳态 `vy=-0.119999`。

### 3. 创造模式飞行

`[实测]` `double_space_fly` 后：

| 维度 | 贴墙 | 开阔 | 结论 |
| --- | --- | --- | --- |
| 水平 `Δz`（16 tick） | **`0.050171`** | `0.374797` | 飞行**仍受** `0.4^n` 水平缩放 |
| 下降 `vy`（Shift） | **`-0.34`** | — | 竖直**不被**钳到 `-0.12` |

`[推断]` 飞行状态下实体仍被写入 `0xc83bbc35`（水平被缩放可证），但飞行控制器在 `EntityInsideSystem` 之后覆写了竖直位移，所以只免竖直钳位。
