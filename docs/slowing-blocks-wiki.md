## 2. 蜘蛛网、甜浆果丛、细雪的共同规则

1. **有效判定盒是 `0.998 × 0.998 × 0.998`**：游戏在检测实体位于方块内部之前，会把玩家碰撞箱的六个面各向内收 **`0.001` 格**。因此身体边缘只贴进方块 `0.0005` 格还不会减速；进入超过 `0.001` 格即触发。
2. **离开立刻恢复（无惯性残余）**：这三种方块每 tick 应用乘数后都会把待应用位移清零，所以一脚迈出方块的当帧就会重置，不会带着低速滑出去。
3. **同时踩中多个时“逐轴取最小值”**：而不是相乘。
   - **蜘蛛网 + 细雪**：水平取 `min(0.25, 0.90) = 0.25`，垂直取 `min(0.05, 1.50) = 0.05`。
   - **甜浆果丛 + 细雪**：水平 `0.80`，垂直 `0.75`。
4. **创造模式站着一样会减速**：只有**真正在空中飞行**的创造玩家才会清空减速；落地踩在蜘蛛网里的创造玩家依然走不动。
5. **甜浆果丛幼苗期（`growth = 0`）也减速且免摔**：幼苗不会扎人，但从 `growth = 0` 开始就已经有完整的 `0.80 / 0.75` 减速与 `0` 摔落伤害保护。
6. **细雪的 `2.5` 格高空跌落穿顶机制**：穿皮革靴从 **`≤ 2.5` 格**高落到细雪上会稳稳站在顶面；若从 **`> 2.5` 格**落入，细雪的碰撞顶面会临时降为 `0.9` 格，让玩家瞬间卡进内部并以 `-0.1176` b/t 向下沉穿（依然 `0` 摔落伤害）。细雪穿靴攀爬速率对照见 [`climb-blocks-wiki.md`](climb-blocks-wiki.md)。

## 3. 细雪冰冻（Freezing）机制

1. **蓄冻与解冻节奏**：
   - 裸足站在细雪 `0.998^3` 效果盒内时，冰冻进度 `p` 每 tick 增加 `1/140`（`140` 刻 = `7.0` 秒满冻）；
   - 离开细雪后每 tick 解冻 `2/140`（`70` 刻 = `3.5` 秒清零）；
   - **穿任意一件皮革护甲**（靴子/护腿/胸甲/头盔）即可完全阻止蓄冻。旁观者模式、创造模式无敌下也不蓄冻。
2. **满冻伤血**：`p = 1.0` 后每 **`40` 刻**（`2` 秒）固定扣 **`1` 点（半颗心）** 生命值。
3. **只拖慢地面速度，不拖慢空中跳跃加速**：
   - 冰冻仅向 `MOVEMENT_SPEED` 添加 `-0.05 × p` 的基础移速惩罚（玩家基础移速从 `0.10` 最低降到 `0.05`，即地面移速与起跳那拍地面加速最多降至 **`50%`**）；
   - 空中基础加速度 `0.02` b/t² 不受该属性影响，因此**只要起跳离开地面，空中每拍增幅依然正常**。

## 4. 灵魂沙：为什么减到 `54.4%` 但停步不打滑？

1. **核心算式**：灵魂沙把下方方块摩擦 `0.6` 放大为 `0.6 × 1.225 = 0.735`（于是 `0.735 × 0.91 = 0.66885`），导致地面加速度变为 `(0.546 / 0.66885)^3 = (1 / 1.225)^3 ≈ 0.54399`（约 **`54.4%`**）。
2. **停步不打滑**：地面滑行阻力阶段不使用这个 `1.225×` 放大值，松开方向键后依然按标准地面阻力 **`0.546`** 迅速刹停。
3. **`+0.1` 格的脚底采样高度**：仅在地面检测 `(x, minY - 0.1, z)`，因此：
   - 灵魂沙上铺**地毯**（厚 `0.0625 < 0.1`）：**依然吃灵魂沙减速**；
   - 灵魂沙上铺**下半砖**（厚 `0.5 > 0.1`）：只读到半砖本身，**完全不减速**；
   - **跳跃到空中**后不受影响。
4. **穿戴灵魂疾行（Soul Speed）**：直接跳过 `1.225×` 减速并改为增速（实测灵魂疾行 I 铁靴步行速度 `0.303284` b/t）。
