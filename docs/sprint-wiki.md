# 基岩版疾跑完全指南：起跑、断疾跑、倒车、延迟与疾跑跳（1.26.51.01）

疾跑在基岩版里不是“按住就跑”那么简单：**它只认前进方向，倒车和侧走会立刻断；撞墙断不断取决于你斜多少度，临界角附近还会逐拍闪烁；但地面和空中都没有延迟，疾跑跳还白送 `+0.2` 水平速度。** 本文按实测数据讲清楚，底层函数与反汇编见 [`notes/sprint-12651.md`](notes/sprint-12651.md)。

> **文档分工**：本文面向玩法与跑酷实战，略去地址；完整四系统入口、`5e-5` 判据、逐 tick 数据见技术文档。
>
> **单位约定**：速度单位 **格/tick**（`1 秒 = 20 tick`）。

## 一、一分钟结论

| 问题 | 答案 |
| --- | --- |
| 怎么起跑？ | 只能**向前**：输入方向要落在前向 ±45° 扇区内（向量长度 ≥ `0.707`、前进分量 > 0、横移 ≤ `0.707`），且“允许疾跑 / 未被饥饿限制” |
| 倒车能疾跑吗？ | **不能**。纯倒车、纯侧走、倒车+侧走都起不来 |
| 跑起来后倒车/侧走呢？ | **立刻断**（切换后的第一个状态拍 `sprint` 就归零） |
| 潜行呢？ | 立刻断 |
| 撞墙会断吗？ | **看角度**：正撞（≤20°）断；**23.5°~24.4° 会逐拍闪烁**；≥24.5° 贴墙滑行稳定不断 |
| 旧 Wiki 的 `f65` 高频闪断？ | **复现了**：临界角 `24.42°`（距墙面 `65.58°`）附近的窄带里，`sprint` 位**每 tick 翻转**一次 |
| 地面有 1-tick 延迟吗？ | **没有**：起步第一拍就是 `1.3×` |
| 空中有延迟吗？ | **没有**：空中第一拍也是 `1.3×` |
| 疾跑跳有额外速度吗？ | **有**：水平 `+0.2` 格/tick（实测 `0.19999~0.20000`），沿朝向分解为 `sin/cos` |

## 二、起跑：只认前向扇区

疾跑判定先看输入向量 `(横移 x, 前进 y)`：

- `y ≥ 0.707` 且 `y > 0`；
- 向量长度 `sqrt(x²+y²) ≥ 0.707`；
- 横移 `|x| ≤ 0.707`；
- 同时未被饥饿（食物等级 ≤6）或其他状态限制疾跑。

翻译成操作：**方向必须在大约前向 ±45° 以内**。

| 输入 | 能起跑吗 |
| --- | --- |
| 只按前进 | ✅ |
| 前进 + 侧移（W+A/D） | ✅ |
| 纯侧移（A/D） | ❌ |
| 只按后退（S） | ❌ |
| 后退 + 侧移 | ❌ |

## 三、保持与取消

| 切换成 | 结果 |
| --- | --- |

| 纯侧走（A/D） | 第一个状态拍就断 |

| 前进 + 跳跃 | 保持（空中仍算疾跑） |
| 前进 + 斜前（W+A/D） | 保持（仍在扇区里） |

## 四、撞墙断疾跑：三个角度区间

判定用的是“水平两轴里谁占优 + 占优轴在碰撞前后的变化量”：

- 若“滑动轴”占优：该轴的位移变化 > `5e-5`，**不断**；
- 若“被墙挡死的轴”占优：该轴位移变化 < `5e-5`，**断**；
- 两条轴接近相等时，占优关系**逐拍交替** → 判定逐拍翻转 → 就是高频闪烁。

实测（正对墙面为 0°，按住前进+疾跑贴墙 41 tick，接触后全程在地面且法向速度 ≤0.02）：

| 与墙面法线夹角 | 结果 |
| --- | --- |
| 0° / 1° / 5° / 10° / 15° / 20° | **单次断**（接触当拍） |
| **23.5° / 24.0° / 24.3° / 24.4°** | **逐拍闪烁**（24~25 次翻转） |
| 24.5° / 24.7° / 25° / 30° / 45° / 65° | **稳定滑行**（`sprint` 保持 1） |

X 墙（侧对另一面墙，镜像角度）：

| yaw（与 X 墙法线夹角） | 结果 |
| --- | --- |
| 90°（0°）/ 89°（1°） | 单次断 |
| **65.6°（24.4°）** | **逐拍闪烁**（29 次翻转） |
| 65.58°（24.42°）/ 65.5°（24.5°）/ 65°（25°）/ 45°（45°） | 稳定滑行 |

两个临界互补：`24.42° + 65.58° = 90°`，与 `arctan(1 − 0.546) ≈ 24.42°` 的推导一致。

跑酷含义：

1. **正撞墙 = 断疾跑**，想保疾跑就别把速度正对着墙送。
2. **斜着擦墙（≥24.5°）可以保疾跑**，适合贴墙滑行过弯。
3. **临界角附近（23.5°~24.4°）会高频闪烁**：`sprint` 每秒翻转好几次，表现为间歇性“掉速—再跑”；这就是社区说的 `f65` 现象，根因是主轴判定逐拍交替，不是随机。

## 五、延迟：地面和空中都没有

| 场景 | 第一拍水平速度 | 倍率 |
| --- | --- | --- |
| 地面走路 | `0.098` | 1.0 |
| 地面疾跑 | `0.1274` | **1.3×** |
| 空中走路 | `0.0196` | 1.0 |
| 空中疾跑 | `0.02548` | **1.3×** |

- 基岩版**没有** Java 1.8 那种“地面起跑晚一拍”的问题：按下疾跑的第一拍加速度就是走路的 `1.3` 倍。
- 空中同样：跳跃后在空中按前进+疾跑，第一拍空中加速也是 `1.3×`。
- 疾跑触发系统在同一 tick 内先于移动和速度更新运行，因此无论地面还是空中，按下前进+疾跑的第一拍都会直接吃到 `1.3×` 加速倍率（地面首拍 `0.098 → 0.1274`、空中首拍 `0.0196 → 0.02548`）。

## 六、疾跑跳的白送 `+0.2`

- 疾跑状态下起跳，会在**水平待执行位移 `mPosDelta`** 上额外加 `0.2` 格/tick，沿朝向分解为 `(-0.2·sin, +0.2·cos)`。
- 实测：
  - 直线疾跑跳：`mpd_z` 从 `0.14578` 跳到 `0.34916`，`0.546×(0.14578+0.1274)+0.2 = 0.34916` 精确成立；
  - 贴墙滑行跳（25°、滑行速度 `0.11859`）：增量向量 `(-0.08450, 0.18126) = 0.2×(sin25°, cos25°)`，模长 `0.19999`；
  - 走路跳、断疾跑后跳：**没有**这份增量。
- **门控看的是疾跑位，不是当前速度**：贴着墙、速度已经被压到 `0.11859`，只要 `sprint` 位还没断，起跳照样拿到 `+0.2`；撞墙断位后起跳就没有。
- 实战：疾跑跳比普通跳远一截；贴墙滑行起跳也能吃到这份加成（前提是没正撞断疾跑）。

## 七、和 Java 版对照

| 维度 | Java 1.8 | Java 1.19.4+ / 1.21.4+ | 基岩版 1.26.51.01 |
| --- | --- | --- | --- |
| 起跑方向 | 前进即可 | 前进即可 | 前向 ±45° 扇区 |

| 疾跑跳冲量 | `+0.2` | `+0.2` | **`+0.2`**（实测） |
| 疾跑倍率 | `0.3 MULTIPLY_TOTAL` | 同 | `0.3 MULTIPLY_TOTAL`（`(1+0.3)×0.1=0.13`） |
