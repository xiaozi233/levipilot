# 使用物品减速与「望远镜加速」指南（基岩版 `1.26.51.01`）

在基岩版里，**按住右键「使用」一件物品时你会变慢**——而且是慢到几乎走不动：
水平输入只剩 **12.25%**（行走 `0.2158` 格/tick → 开镜 `0.0265` 格/tick）。
这个数字来自一个很反直觉的实现：物品自己声明的减速系数是 **`0.35`**，游戏在把它乘进
输入向量时**又平方了一次**，于是 `0.35 → 0.1225`。

关于社区长期标注 `Super mysterious` 的「**望远镜加速**」：在 `1.26.51.01` 里，
**它作为速度增益并不存在**。望远镜没有专属倍率（和面包、弓完全一样是 `0.35`），
也不存在松手残留、起用免检拍、切槽逃逸或与疾跑叠加的窗口。本文最后一节给出可逐拍复核的判据。

> **文档分工**：本文面向跑酷/速通/机制理解，略去反编译地址与组件编号；
> 完整反汇编、20 处组件引用与逐 tick 原始数据见 [`notes/spyglass-item-use-12651.md`](notes/spyglass-item-use-12651.md)。
> 潜行与爬行见 [`sneaking-crawling-wiki.md`](sneaking-crawling-wiki.md)，疾跑见 [`sprint-wiki.md`](sprint-wiki.md)。
>
> **单位约定**：速度单位是 **格/tick**（`1 秒 = 20 tick`），括号内附 **格/秒**。

## 一、一分钟结论速查

| 常见疑问 | 基岩版 `1.26.51.01` 实际表现 | 关键数值 |
| --- | --- | --- |
| **用物品会变多慢？** | 水平输入 **`12.25%`**，几乎是"原地挪" | 行走 `0.2158` → 用物品 `0.0265` 格/tick（`4.32` → `0.53` 格/s） |
| **为什么是 `0.1225`？** | 物品系数 `0.35`，游戏**再平方一次** | `0.35² = 0.1225`；不是乘了两次 `0.35` |
| **望远镜会比别的物品更慢吗？** | **不会，完全一样** | 望远镜/弓/弩/三叉戟/金苹果/药水/奶桶/面包都是 `0.1225` |
| **开镜能不能加速？** | **不能**，没有任何加速路径 | 逐拍点按最高 `0.2004` 仍低于行走 `0.2158`，且没有一拍超出行走加速曲线 |
| **开镜时还能跳吗？** | **能，而且跳跃高度完全不变** | 跳跃初速 `0.42` 逐位相同；只是水平操控变 12.25% |
| **开镜 + 潜行怎么叠加？** | **相乘** | `0.3 × 0.1225 = 0.03675`（`3.7%`） |
| **开镜 + 迅捷潜行 III？** | **相乘** | `0.75 × 0.1225 = 0.091875`（`9.2%`） |
| **开镜时能疾跑吗？** | **不能起跑；疾跑中开镜有 1 拍过渡** | 开镜那一拍仍是疾跑（`12.25%` 还没生效），下一拍才归零 |
| **松手多久能再跑？** | **下一拍** | 松手后第 1 个记录拍即恢复疾跑 |
| **切快捷栏能甩掉减速吗？** | **看切到什么** | 切到能继续用的物品仍是 `12.25%`；切到盾牌/方块会直接结束使用（那时也没在用物品） |
| **45° 斜着走会不会更划算？** | 还是 `12.25%`，只是再乘 `1/√2` | `0.1225 × 0.7071 = 0.08662` |
| **空中用物品会减速吗？** | **会，同倍率** | 开镜起跳时水平加速度同样是 `12.25%` |
| **举盾会不会更慢？** | **不会额外减速** | 盾牌靠**潜行**触发，乘数就是纯潜行 `0.3`，没有 `12.25%` 叠加 |

## 二、这个 `12.25%` 是怎么来的

三段话讲完：

1. **物品自己带一个系数**，存在物品的 `use_modifiers` 数据里，绝大多数"能长按右键"的物品都是
   **`0.35`**。手上没有任何 `use_modifiers` 的物品（或数据里没写这一项）时，游戏也回落到 `0.35`。
2. 系统把系数写进一个**一拍就消失的临时组件**（每 tick 末整张表被清空，所以你永远查不到它）。
3. 下一套系统把这个系数**平方**后乘进你的**水平移动输入**：`0.35 × 0.35 = 0.1225`。

第 3 步的平方是 `0.1225` 的唯一来源。它不是"物品写了 0.1225"，也不是"乘了两次 0.35"——
常量只有一个 `0.35`，另外一次是 `m²` 的变换。这一点很重要：**如果哪天官方去掉平方，
同样按住右键就只会慢到 35%，而不是 12.25%**。

> 一个副作用：系数恰好等于 `1.0` 时，游戏**干脆不创建这个临时组件**——也就是"完全不减速"。
> 所以"没有这个组件"和"系数 1.0"是同一件事。

## 三、各类物品有多慢（实测）

同一场地、同一走法，按 `mMoveVector` 逐拍直读：

| 物品 | 怎么用 | 速度倍率 | 备注 |
| --- | --- | --- | --- |
| 望远镜 | 长按右键开镜 | **`12.25%`** | 与其它物品完全同值 |
| 弓 | 长按右键拉弓（需箭） | **`12.25%`** | 拉弓全程减速 |
| 弩 | 长按右键装填（需箭） | **`12.25%`** | 同上 |
| 三叉戟 | 长按右键蓄力投掷 | **`12.25%`** | 非激流 |
| 金苹果 | 长按右键吃 | **`12.25%`** | 满饥饿也能吃，最稳定的对照 |
| 药水 / 奶桶 | 长按右键喝 | **`12.25%`** | 喝完物品消失 |
| 面包等食物 | 长按右键吃 | **`12.25%`** | 满饥饿时使用窗口可能提前中断 |
| 山羊角 | 长按右键吹 | **`12.25%`（约 8 拍后结束）** | 系数与其它物品同档；但一按前进约 8 拍后使用会结束，之后回到全速 |
| 盾牌（主手/副手） | **按住潜行**举盾 | **`30%`（纯潜行）** | 不走右键、不进入"使用"状态，所以**没有** `12.25%`，也没有格挡专属减速 |
| 刷子 | 对着可疑沙长按右键 | **未测到** | 两轮都没取得使用窗口，未测 |

两条要点：

- **望远镜不是特殊物品**。它和弓、食物共用同一个 `0.35`，所以"望远镜更慢/更快"的说法都不成立。
- 山羊角那一行是"**会减速，但移动会让使用提前结束**"；盾牌是"**根本不走这条管线**"；刷子是"**没测到**"。
  三者含义不同，别都读成"不减速"。

## 四、和潜行、疾跑、空中、斜走怎么叠加

### 4.1 潜行：**相乘**

| 组合 | 速度倍率 | 相当于 |
| --- | --- | --- |
| 开镜行走 | `0.1225` | 行走的 12.25% |
| 开镜 + 潜行 | `0.03675` | `0.3 × 0.1225` |
| 开镜 + 潜行 + 迅捷潜行 III | `0.091875` | `0.75 × 0.1225` |

是**乘积**，不是"取更慢的那个"，也不是"后者覆盖前者"。
所以"迅捷潜行"能明显救回一截：III 级从 `3.7%` 提到 `9.2%`。

### 4.2 疾跑：起不来、被掐断、松手就恢复

- **正在用物品时不能起跑**：只要这一拍手上还在用物品，起跑请求就被拒绝。
- **疾跑中开镜是"慢一拍"才断**：开镜那一拍仍按疾跑结算（`sprint` 仍是 1、速度维持 `0.28064`、
  水平输入还没被乘 `12.25%`），**下一拍**才切到 `0.1225` 并掉到 `0.16516`。
  这一拍**不会让你更快**——速度只是保持在原来的 `0.28064`，没有任何超调。
- **松手后下一拍即可重新疾跑**：速度序列 `0.02649 → 0.02649 → 0.14185 → 0.20483 → …`，
  和正常起步同量级。

### 4.3 空中：水平减速，跳跃不变

- 空中用物品的加速度是空中行走的 **`12.25%`**（`0.002401` vs `0.019601`），与地面同倍率。
- **跳跃初速不受影响**：**持续按住右键开镜**时起跳，竖直速度首拍仍是 `0.419998`，与普通跳逐位相同；
  起跳那一拍的水平输入仍是 `0.1225`。也就是说"开镜跳"能跳满高度，只是水平方向几乎推不动。

### 4.4 45° 斜走：先归一化，再乘

斜着走仍然是 `12.25%`，只是归一化让它再乘 `1/√2`：

```text
W+A + 开镜 = 0.1225 × 0.7071 = 0.08662   （行走斜走是 0.7071）
```

所以斜走并不能"绕过"减速，它和行走斜走是同一个比例关系。

### 4.5 切快捷栏：取决于切到什么

保持按住右键、边走边切槽（一次长按、中途只换槽、不松右键）：

| 切到 | 使用状态 | 倍率 |
| --- | --- | --- |
| 面包 | 继续 | `12.25%` |
| 盾牌 | **结束** | `100%` |
| 山羊角 | **继续**（约 8 拍后又结束） | `12.25%` |
| 石头 | **结束** | `100%` |

结论：**能不能"甩掉"减速，取决于新物品能不能维持使用**。
切到面包/山羊角这类还能右键使用的物品，减速照旧；切到盾牌/方块，使用直接结束、减速也没了——
但那时你手上已经没有正在使用的物品，所以"边开镜边全速"这个组合不存在。

## 五、「望远镜加速」到底存不存在

**在 `1.26.51.01`：不存在。** 下面是可逐拍复核的排除表（想要原始数字见
[`notes/spyglass-item-use-12651.md`](notes/spyglass-item-use-12651.md) §6）：

| 传说里的机制 | 实测/代码结果 |
| --- | --- |
| 望远镜有专属系数 | `√0.1225 = 0.35`，和面包逐位相同 |
| 松手后乘数残留、再叠加 | 松手后下一拍就回到 `1.0`；临时组件每拍末被整表清空 |
| 起用当拍"还没减速"可以先冲 | 开镜首拍就已经是 `0.1225` |
| 开镜 + 疾跑 = `1.3×` 叠加 | 开镜那一拍疾跑仍在，但速度**不增**（维持 `0.28064`），下一拍疾跑归零；起跑被拒 |
| 空中开镜不减速 | 空中同样是 `12.25%`；**持续开镜起跳**的起跳拍 `mi_z` 仍是 `0.1225` |
| 切槽/切物品甩掉减速 | 只有切到"不能维持使用"的物品才会结束减速，那时已不在使用任何物品 |
| 高频点按制造"半减速" | 逐拍在 `0.1225`/`1.0` 间硬切换，最高 `0.2004` < 行走 `0.2158`，无一拍越界 |
| 点按 + 疾跑键一起抖 | 58 拍里 25 拍疾跑生效（只在不按右键的拍），同样**没有一拍**超过疾跑加速曲线 |

点按段的判据特别直观：关镜拍的速度严格满足"从当前速度按行走加速"
（`0.02405 → 0.11121 ≈ 0.546 × 0.02405 + 0.097982`），没有任何一拍超出这条曲线。
**只要有一拍超过 `0.546·v + a`（行走 `a=0.097982`、疾跑 `a=0.1274`），就说明存在额外加速源；
本轮两个点按变体的逐拍扫描违反数都是 0。**
普通点按能到 `0.2004` 是因为"关镜"的拍数够长时玩家本来就会加速到接近行走稳态——那不是加速，是没在用物品。

那"望远镜 glitch"是什么？本课题能负责地说：

- 望远镜**确实**有自己的**镜头缩放（FOV）**和开镜手部动作，但那是相机/渲染路径，不在移动倍率里；
  本文没有测 FOV，也不把"看起来更快"当成速度变化。
- 开镜**不影响跳跃初速**，也不影响台阶/碰撞，所以"开镜跳"几何上与普通跳一致，只是水平操控被压到 12.25%。
- 如果历史版本真有过望远镜加速，`1.26.51.01` 已经把"系数 >1"和"残留"两条通道都堵住了。

## 六、实用要点（跑酷/速通向）

1. **开镜=几乎站住**：`12.25%` 的水平输入，靠它调整站位可以做到"毫米级"微调，
   比潜行（`30%`）细得多。
2. **开镜不损失跳跃高度**：需要"原地起跳+空中微调"时，开镜是比潜行更细的水平控制。
3. **想跑就别举东西**：任何"能长按右键"的物品都会把疾跑掐断（开镜是慢一拍掐断），起跑被拒。
4. **松手即恢复**：松开右键后的下一拍就能重新疾跑，不需要额外等待或重新落地。
5. **潜行 + 开镜会非常慢**（`3.7%`），除非有迅捷潜行 III（`9.2%`）。
6. **切槽不是逃生门**：想解除减速必须真正停止使用（松右键或换到盾牌/方块这类不能维持使用的物品）。
7. **举盾靠潜行，不靠右键**：盾牌不会给你额外的 `12.25%`，行走乘数就是潜行的 `30%`。

## 七、边界（本文没有覆盖的部分）

- **FOV/镜头**：开镜的视觉缩放没有测；本文只谈移动倍率。
- **创造飞行、骑乘/载具、游泳、鞘翅、攀爬**：都没有覆盖。
- **盾牌/刷子**：盾牌确认不走物品使用管线（潜行触发，乘数 `30%`），但"格挡状态本身"没有可用的
  ECS 组件来证明；刷子两轮都没取得使用窗口，倍率未测。
- **山羊角/弩**：使用窗口会提前结束（角约 8 拍、弩在装填完成后），"为什么结束"没有静态闭环。
- **迅捷潜行 I/II**：只测了 III；I/II 的 `0.45/0.60` 见潜行专文。
- **多人服务端**：本轮全部是单机世界，服务端权威移动的收回/回滚不在范围。
