# 基岩版上台阶、Jump Cancel、固体 Blip 与 Grind 机制指南（`1.26.51.01`）

在《我的世界》基岩版（MCBE）中，“走上低矮方块”远不只是自动迈半格那么简单：它的最大步高是 **`0.5625` 格（9/16）**、上台阶时**不丢水平速度且不断疾跑**，而且拥有与 Java `1.12.2` 同构的准入规则——既会在试探路径时先临时拿掉头顶天花板、也在**起跳首拍**和**落地当拍**照样放行。于是，**紧贴台阶或天花板前缘起跳的 Step-Assist Jump Cancel**、**落地拍撞边的保速固体 Blip**，以及**靠松键清零 `10` tick 冷却的 `3` tick 点按 Grind**，在基岩版里全部真实成立。

> **文档分工**：本文面向玩法理解、跑酷线路设计与 Java/Bedrock 机制对照，略去底层反编译地址与内部组件编号；完整系统注册顺序、试探汇编与逐 tick 原始数据请参阅 [`notes/stepping-12651.md`](notes/stepping-12651.md)，撞墙断疾跑细节联动 [`sprint-wiki.md`](sprint-wiki.md)，候选碰撞盒下探规则见 [`notes/bounce-12651.md`](notes/bounce-12651.md)。
>
> **单位约定**：文中速度单位默认是 **格/tick**（$1\text{ 秒} = 20\text{ tick}$），括号内附 **格/秒**；高度均指脚底相对地面或目标表面的差值。

## 一、一分钟结论速查

| 常见疑问 / 场景 | 基岩版 `1.26.51.01` 实际表现 | 关键机制 / 实测数值 |
| --- | --- | --- |
| **平地最高能直接走上多高？** | **`0.5625` 格（9/16）** | `0.5`（4 层雪/半砖）与 `0.5625`（切石机）一步走上；`0.625`（5 层雪）被挡停 |
| **走上台阶会掉速或断疾跑吗？** | **不会** | `0.5625` 台阶上拍瞬间水平速度仍是 `0.2159`（走）/ `0.2806`（跑），疾跑不断；`0.625` 撞死才断 |
| **头顶有矮天花板还能上台阶吗？** | **取决于最终站位是否顶头** | 净空 `1.2` 格时可走上 `0.5` 台阶；净空只有 `0.2` 格时被终点复核拒绝；**从矮檐下向外跨台阶也一样**——只要终点 AABB 还压着身后矮顶就上不去，必须让矮顶提前结束 |
| **潜行或创造飞行时还能自动上台阶吗？** | **都能，边界仍是 `0.5625`** | 潜行走上 `0.5625`、被 `0.625` 挡住；平飞（`flying=true`）同样能走上 `0.5625` |
| **紧贴低台阶前沿起跳会怎样？** | **直接站上台阶，不往上跳** | Step-Assist 吃掉 `+0.42` 起跳、按台阶高抬升，水平保留全速 **`0.3274` 格/tick**（`6.55` 格/s） |
| **撞上矮天花板前缘起跳呢？** | **吃掉起跳并全速贴地钻入** | 同属 Step-Assist Jump Cancel：升高 `0`、水平保持 **`0.3274` 格/tick** 钻进矮顶 |
| **在矮顶正下方起跳呢？** | **请求照写，升幅被天花板裁短** | `+0.42` 起跳在 `0.2` 格净空下只升 **`+0.2` 格**，经两拍落回地面 |
| **下落擦台阶边能保速抬升吗（固体 Blip）？** | **能，但必须撞在落地那一拍** | 对齐落地拍后水平 **`0.2524` 格/tick** 一点不掉，当拍从离地 `0.1213` 格一步抬 **`+0.4412` 格**上顶 |
| **矮顶 Grind 最快能叠到多快？** | **点按每 `3` tick 一跳，峰值 `0.6318`** | 松开跳跃键会清零 `10` tick 冷却；长按不松只有 `10` tick 一跳（峰值 `0.4822`） |

## 二、基岩版 vs Java `1.12.2` 核心差异

| 对比维度 | Java 版（JE `1.12.2`） | 基岩版（BE `1.26.51.01`） | 实战 / 跑酷影响 |
| --- | --- | --- | --- |
| **最大自动步高** | **`0.6` 格** | **`0.5625` 格（9/16）** | 常见 `0.5`/`0.5625`/`0.625` 一致；但 **`0.5625 < h ≤ 0.6`** 的组合落差只有 JE 能走上，BE 会挡停 |
| **准入门禁条件** | 在地面 / 落地拍 / 水平碰撞 | **结构同构**：步高 `> 0` + 水平碰撞 +（起拍在地面 / 本拍下落落地 / **飞行** / 一次性标志） | 起跳第 `1` 拍仍算在地面、落地那一拍也满足准入；BE 还额外放行创造飞行 |
| **试探与顶头检查** | **双方案竞争**：扩展盒限高 `Y↑` 与原盒 `Y↑0.6` 各试探一次择优，再 `Y↓` | 先**临时删掉原头顶以上天花板盒**，单次跑 `Y↑→X→Z→Y↓` 后再用完整方块复核终点 | **从矮天花板下向外跨上无顶台阶时**，只有终点 AABB 完全离开身后矮顶才能走上；BE 的终点复核同样会否决“还压着矮顶”的抬升，并不会仅凭预删就穿檐 |
| **数值精度** | `double`（64 位） | `float32`（32 位） | 远距离大坐标下，BE 更早出现台阶边缘与碰撞的精度漂移 |
| **上台阶后的速度保留** | 常规移动与碰撞箱推进耦合更新 | **只改本拍位移请求**，体内攒下的待执行位移原封不动 | 走上台阶瞬间不吞水平余速，松手或立刻起跳都能顺滑衔接 |
| **固体 Blip** | 存在（落地拍触发、保速） | **存在**：碰撞与落地同拍时一格不掉速、直接抬升上顶 | 对拍位要求极严格，早撞 `2` tick 就会先被挡停 |
| **Jump Cancel / Grind** | 存在；长按也有 `10` tick 连跳冷却，松键可重置 | **同族**：`0.5`/`0.5625` 贴边起跳可触发 Jump Cancel；长按 `10` tick 冷却、点按最快 **`3` tick** 一跳 | 矮顶通道手速点按可达 `0.6318` 格/tick（约 `12.64` 格/s）；但无顶台阶阶梯不易稳定连锁 |

## 三、自动上台阶的三道门禁与 `0.5625` 步高边界

基岩版每 tick 先按常规 `Y → X → Z` 推进一次，只要撞上了障碍侧面，就会按顺序检查三道门禁决定要不要“改走上台阶”：

```text
第 1 道门（准入）：步高 > 0 且发生水平碰撞
  ├─ 起拍时就在地面（注：起跳第 1 拍仍带着该标记！）
  ├─ 或本拍正在下落并撞地停住
  └─ 或处于飞行 / 一次性允许标志状态
        │ 通过
        ▼
第 2 道门（无顶试探）：临时滤掉原头顶上方的天花板盒
  └─ 按 max_step(0.5625) 先抬升 → 沿 X → 沿 Z 推进 → 再按实际抬升量向下回落贴合
        │
        ▼
第 3 道门（终点复核）：把所有完整方块放回来检查
  ├─ 新位置会与任意方块相交（如头顶撞矮顶） ──▶ 拒绝，维持常规撞墙结果
  └─ 终点干净，且新水平位移平方 > 常规水平位移平方 ──▶ 采纳上台阶！
```

### 1. 为什么低矮天花板会决定“上不上得去”？

因为第 2 道门先移走了头顶天花板、第 3 道门才把天花板放回来检验终点站姿：

| 走廊头顶净空 | 目标台阶高度 | 最终结果 | 原因 |
| --- | --- | --- | --- |
| **`1.2` 格** | `0.5` 格 | **顺利走上** | 站上 `0.5` 台阶后头顶仍余 `0.7` 格，终态不撞头 |
| **`0.2` 格** | `0.5` 格 | **被拒绝，卡在前沿** | 站上台阶后头顶会穿进天花板 `0.3` 格，被第 3 道门一票否决 |

- **从矮天花板下往外跨出**：第 2 道门确实会先移走原头顶盒，但第 3 道门用的是**完整方块表**。如果终点 AABB 仍和身后的矮顶在水平方向重叠（典型：矮顶最后一格正好压在台阶前缘），抬升后的头顶会穿进矮顶，直接被否决、卡在前沿；只有让矮顶提前一格结束、候选 AABB 完全离开矮顶，才能顺利走上。**“预删头顶盒”只影响试探，不等于可以穿檐。**

### 2. 四档步高实测：`0.5` / `0.5625` / `0.59375` / `0.625`

用**满宽单盒**方块实测边界（注：堆肥桶 `composter_fill_level = 4` 虽然内底板是 `0.5625`，但四周外壁高达 `1.0` 格，从侧边走会先撞外壁；切石机才是干净的 `0.5625` 单盒）：

| 台阶方块 | 台阶高度 | 走路表现 | 疾跑表现 |
| --- | --- | --- | --- |
| **`4` 层雪片 / 半砖** | `0.5` 格 | 一步走上，水平稳态 **`0.2159`** 不掉速 | 一步走上，水平稳态 **`0.2806`**，疾跑位全程不断 |
| **切石机** | **`0.5625` 格** | 一步走上，水平稳态 **`0.2159`** 不掉速 | 一步走上，水平稳态 **`0.2806`**，疾跑位全程不断 |
| **横置铁链**（`pillar_axis=x`） | **`0.59375` 格**（19/32） | 比步高高 `0.03125`，被挡在前沿 | 同样被挡，不会“冲过去” |
| **`5` 层雪片** | `0.625` 格 | 超过 `0.5625`，被挡死在前沿 | 被挡停归零，次拍触发撞墙断疾跑 |

- **为什么能确定边界就是 `0.5625`？** 横置铁链的碰撞顶面 `0.59375` 是游戏里少数落在 `0.5625` 与 `0.625` 之间的真实高度；它和 `0.625` 都被挡，说明上限不是 `0.625` 也不是“只要比 `0.5` 高就行”。抓取候选盒时向下多探的 `step × 1.01 ≈ 0.5681` 只负责把贴脚方块纳入候选，抬升高度本身仍是 `0.5625`。

- **为什么上台阶不会断疾跑？** 走上 `0.5`/`0.5625` 台阶时，水平坐标每拍都实实在在往前推进（远大于 [`sprint-wiki.md`](sprint-wiki.md) 中的 `5e-5` 格断疾跑阈值），只有被 `0.625` 真正顶停才会断掉。
- **为什么上台阶不吞动量？** 第 3 道门采纳时**只修改本拍送去碰撞解算的位移请求**，不会清空或改写身体内原本攒着的待执行位移（例如竖直待执行位移仍保持地面重力微元 `-0.0784`，水平余速也完好保留），因此上台阶之后紧接着起跳或松手，余速照样按常规地面摩擦释放。
- **和黏液块反弹的隐藏联动**：抓取候选碰撞盒时，上台阶会把向下搜索下界扩展到 **`step × 1.01 ≈ 0.5681` 格**，这也是 [`notes/bounce-12651.md`](notes/bounce-12651.md) 中黏液块上层覆盖箱提前被抓进候选表的原因。

## 四、Step-Assist Jump Cancel：贴台阶与天花板前缘起跳

### 1. 紧贴 `0.5` / `0.5625` 台阶前沿起跳

由于**在地面按跳跃后的第 `1` 个运动拍仍保留“起拍在地面”标记**（该标记直到 tick 末尾才更新），如果玩家紧贴在低于 `0.5625` 格的台阶边缘起跳，常规路径先升 `+0.42` 仍够不到台阶顶面，往前水平推进就会撞上台阶侧面。此时上台阶系统立刻通过第 1 道门接管：

```text
第 1 拍（起跳按输入）：写入 +0.42 起跳冲量 + 0.2 疾跑水平冲量（仍带着“在地面”标记）
第 2 拍（推进与碰撞）：常规 +0.42 没越过台阶顶，水平撞到台阶侧面 → Step-Assist 接管！
         └─ 直接放上台阶顶面：垂直位移 +0.5 / +0.5625（而非 +0.42）
         └─ 水平全速保留 0.3274 格/tick（6.55 格/s）
         └─ 原有的 +0.42 上升惯性被整拍替换，待执行垂直位移直接归回地面值 -0.0784
第 3 拍以后：下一拍落地即可立刻重新点按跳跃，在 0.5 台阶上第 2 跳瞬间爆发至 0.5133 格/tick（10.27 格/s）！
```

| 台阶高度 | 紧贴起跳后第 2 拍脚底升幅 | 保留水平速度 | 待执行垂直位移 | 第 2 跳瞬间水平速度 |
| --- | --- | --- | --- | --- |
| **`0.5` 格** | **`+0.5`** | **`0.3274`**（全速） | `-0.0784`（立即归位） | **`0.5133`**（`10.27` 格/s） |
| **`0.5625` 格** | **`+0.5625`** | **`0.3274`**（全速） | `-0.0784`（立即归位） | **`0.4858`**（`9.72` 格/s） |

### 2. 撞上矮天花板前缘起跳

如果起跳点前方 `1` 格处是一片仅高出地面 `2` 格的矮天花板（边缘正对着跳跃上升后的头部高度），基岩版同样会触发 **Step-Assist Jump Cancel**：起跳上升并向前撞上天花板前缘的水平碰撞通过了第 1 道门；第 2 道门临时移走天花板、试探 `Y↑→X→Z→Y↓` 后回落到地面高度，第 3 道门检查矮顶下方终点不撞头且水平距离更远——结果就是**玩家的 `+0.42` 垂直起跳被整拍吃掉（实际升高 `0` 格），同时以完整 `0.3274` 格/tick 全速贴地钻入矮天花板下方**。它是“免费取消起跳并钻入”，而非额外抬升的 Ceiling Blip。

### 3. 区分“正上方矮顶截断”

如果在起跳之前**整个人就已经站在 `2` 格矮天花板（净空 `0.2` 格）正下方**，则不存在水平碰撞、也不存在能绕开的起点，此时第 3 道门不会通过：游戏照常写入 `+0.42` 起跳请求与 `+0.2` 疾跑跳水平冲量，但头顶方块会把本拍实际上升死死压在 **`+0.2` 格**，随后两拍经 `-0.0784` 和 `-0.1216` 落回地面。

## 五、固体 Blip（Solid Blip）：保速抬升的拍位密码

基岩版确实存在与 Java 1.8 同类的**保速固体 Blip**，但它的触发条件对拍位极其苛刻：**“下落触地那一拍”和“首次水平擦到低台阶前沿”必须重合在同一个 tick**。

| 下落撞边时机 | 当拍准入状态 | 当拍水平速度 | 高度变化与手感 |
| --- | --- | --- | --- |
| **提前 `2` 拍在半空撞上侧面** | 尚未落地，**准入不通过** | 被墙挡成 `0.0719` → 下一拍 **`0`** | 先在墙前停死、再往下掉 `2` 拍，等真正触地那一拍才被抬上去（**不保速**） |
| **精准对齐落地同拍擦上前沿** | **本拍下落撞地，准入立刻通过** | **`0.2524`**（与空地对照组**一模一样，零掉速**） | 同拍从距地面 `0.1213` 格处直接一步抬 **`+0.4412` 格**直达 `0.5625` 台阶顶面 |

也就是说，只要起跳距离和落点算得足够准，在落回地面的同一拍擦到 `0.5`/`0.5625` 台阶边缘，角色就会**一格水平速度都不掉地瞬间弹上台阶顶面**；但只要早碰哪怕 `1~2` tick，空中那几拍就只能先把水平动量撞清零再被动爬上去。

## 六、Grind 连跳加速：为什么点按比长按快 `31%`？

### 1. `10` tick 冷却的真相：松键即清零

基岩版同样有一个经典的跳跃冷却计数器（`10` tick）：每次起跳都会把冷却设为 **`10`**、每 tick 减 **`1`**，归零后才允许下一次起跳。但**只要松开跳跃键，系统就会在下一次检测时把冷却直接清零**——只有一直按住空格不松时，冷却才会被老实倒数满 `10` 拍。

### 2. 矮天花板走廊实测：点按 `3` tick 极限

在头顶仅余 `0.2` 格净空的 `2` 格矮天花板走廊内全程疾跑前进（自由平地疾跑稳态为 `0.2806` 格/tick）：

| 跳跃操作方式 | 实测跳跃冲量间隔 | 水平最高速度（格/tick） | 格/秒 | 对比自由疾跑 |
| --- | --- | --- | --- | --- |
| **点按（按 `1` 拍 / 松 `1` 拍）** | **最快每 `3` tick 一跳**（`3~5` 波动） | **`0.6318`** | **`12.64`** | **`2.25×`**（比长按快 **`31%`**） |
| 点按（按 `1` 拍 / 松 `2` 拍） | `4~6` tick | `0.5591` | `11.18` | `1.99×` |
| 点按（按 `1` 拍 / 松 `3` 拍） | `4~7` tick | `0.5425` | `10.85` | `1.93×` |
| 点按（按 `1` 拍 / 松 `4` 拍） | `6~8` tick | `0.4991` | `9.98` | `1.78×` |
| 点按（按 `1` 拍 / 松 `9` 拍） | `10~12` tick | `0.4822` | `9.64` | `1.72×` |
| **全程长按空格不松** | **固定 `10` tick 一跳** | **`0.4822`** | **`9.64`** | **`1.72×`** |
| **连续天花板前缘点按（`1 / 2`）** | `3~6` tick | `0.6075` | `12.15` | `2.16×` |
| 无顶连续 `0.5` 台阶阶梯（`1 / 2`） | `10~15` tick（未稳定连锁） | `0.5132` | `10.26` | `1.83×` |
| **`0.5` 台阶 + 空档 + 矮顶前缘组合（`1 / 2`）** | **`4~14` tick**（可连锁但不稳定） | 与纯矮顶同量级 | — | 高于纯阶梯 |

- **为什么最快只能每 `3` tick 一跳？** 在 `0.2` 格净空矮顶下起跳，`1` 拍升 `+0.2` 格，随后固定要花 `2` 拍（`-0.0784` 和 `-0.1216`）落回地面——`1 + 2 = 3` tick 本身就是物理落地周期的下限。手速或宏做到每落回地面就点按一次，每 `3` tick 都能吃满一次疾跑跳 `+0.2` 水平冲量，速度立刻冲上 `0.6318` 格/tick。
- **逐拍长什么样？** 最快的一对相邻冲量是：`t` 拍写 `+0.42`（脚仍在地面）→ `t+1` 升到 `+0.2` → `t+2` 落到 `+0.1216` → `t+3` 落回地面并且**同拍再写 `+0.42`**。这四行就是 `+0.2` 上升、`-0.0784`、`-0.1216` 两拍下落的完整账；落地标记要到这一拍末尾才更新，所以 `t+3` 是第一个能再次起跳的 tick。
- **为什么连续半砖阶梯没能像矮顶那样连续 Grind？** 没有低天花板压头时，角色会在踏上阶梯后完整跳到半空，滞空时间远长于只有 `2` 拍的矮顶跳跃，固定节奏点按大多落在空中而非恰好踩到次级台阶前沿的接地窗口，因此间隔拉长到 `10~15` tick。把台阶、空档和矮顶前缘按周期 `6` 组合后可以产生更多 Jump Cancel 冲量（最短 `4` tick），但仍会被台阶/空档打断，达不到纯矮顶的稳定 `3~6` tick。

## 七、跑酷实战速用清单

1. **做高速斜坡/台阶赛道选 `0.5` 或 `0.5625`**：半砖、4 层雪与切石机（注意堆肥桶 `fill=4` 外壁高 `1.0` 格不行）走上去都不丢水平速度、不断疾跑；超过 `0.5625` 的 `5` 层雪（`0.625`）则会直接顶停断跑。
2. **矮顶下上台阶留够 `≥ 0.5` 格净空**：试探过程先忽略头顶再复核终点，只要踏上去之后头顶空间足够就不会被拒；`0.2` 格净空下上不去 `0.5` 台阶。
3. **想靠固体 Blip 白嫖高度，必须对齐落地拍**：只有下落触地同一拍擦到低台阶前沿才能零掉速抬升 `+0.4412` 格；提前半空撞上会立刻掉速停顿。
4. **矮顶通道冲刺务必点按，不要按死空格**：长按会被锁在 `10` tick 一跳（`0.4822` 格/tick），落地瞬间点按松开可压到 `3` tick 一跳（`0.6318` 格/tick）。
5. **用贴台阶/天花板前缘起跳来免费取消高度**：紧贴 `0.5`/`0.5625` 台阶起跳可直接全速站上台阶并立刻接下一跳（第 2 跳达 `0.5133`）；贴天花板前缘起跳则能把垂直跳高吞成 `0`、全速贴地切入矮顶。
6. **潜行与创造飞行不用绕路**：两者都保留自动步高，`0.5625` 以内照常上；潜行只是速度降到 `0.3×` 左右，飞行则是 `isFlying` 直接放行，不会因为“没站在地面”而失去上台阶能力。
7. **别指望从矮檐下“穿檐”跨台阶**：矮顶最后一格压在台阶前缘时，落脚后头顶会穿进矮顶，终点复核照样拒绝；要么把矮顶建得离台阶远一格，要么先退出来再上。

> **覆盖边界**：以上数据基于基岩版 `1.26.51.01` 平地、冲刺跳、`0.2` 净空矮天花板及满宽/单盒台阶实测；`0.59375` 用横置铁链补点，已确认 `0.5625` 精确上限。潜行与创造飞行已补测；鞘翅、水中/游泳姿态、载具乘客（马/船/矿车）与骑乘时的 `1.0625` 步高仍未做实机对照（`1.0625` 的三值条件已静态闭合）。完整逐 tick 记录与静态反汇编地址见 [`notes/stepping-12651.md`](notes/stepping-12651.md)。
