# 文档交付检查清单

## 事实与范围

- [ ] 核对了当前代码、配置和适用测试，没有仅按旧文档改写。
- [ ] 当前事实、历史证据、推断和未知项有清楚区分。
- [ ] 命令、字段、默认值、权限、单位、容量和错误语义准确。
- [ ] 接受、完成、实际效果及回读要求没有混淆。
- [ ] 最新验收与未运行、skip、未复现、未定位范围如实保留。

## 结构与精简

- [ ] 每篇文档有明确用途，详细事实只有一个正主。
- [ ] 没有按日期堆叠过程、重复验收表或复制旧提示词。
- [ ] 删除正文后仍保留前提、关键数值、限制和守卫依赖事实。
- [ ] 删除文件前检查了引用，索引和另见链接已同步。
- [ ] 临时报告和运行产物没有误加入 Git。

## 可读性与公开性

- [ ] 命令可直接执行，路径、参数和类型名与代码一致。
- [ ] 没有本机用户名、私有目录、令牌或不必要的会话信息。
- [ ] 逆向公开结论保留证据等级、复核路径和撤回关系。

## 实际检查

按改动范围执行，不为了“全绿”跳过失败：

```bash
py -3.11 skills/bedrock-re/checks/lint_public.py
py -3.11 -m unittest tests.test_landing -v
py -3.11 skills/bedrock-re/checks/guards/check_statevector.py
py -3.11 skills/bedrock-re/checks/guards/check_eye_feet.py
```

- [ ] 所有 Markdown 相对链接的目标存在，锚点指向仍有意义。
- [ ] `git diff --check` 通过，工作树只有预期文件。
- [ ] offsets/roles/机制相关内容已运行对应生成或角色守卫。
- [ ] 最终说明列出实际运行的检查和未运行范围，没有把文档检查说成完整程序验收。
